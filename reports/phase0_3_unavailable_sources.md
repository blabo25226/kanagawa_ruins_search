# Phase 0.3 未取得・保留データおよび申請手順調査レポート

**プロジェクト**: 神奈川県廃墟調査プロジェクト  
**作成日**: 2026-10-10  
**作成フェーズ**: Phase 0.3（神奈川県全域＋隣接市区町村の地理データ一括収集）  

---

## 1. 概要

本プロジェクトでは、「利用条件の遵守」「認証回避・自動取得の禁止」「無料・合法的なオープンアクセス優先」の原則を定めている。
本レポートは、Phase 0.3において自動ダウンロードの対象から除外したデータ、有料・登録必須のデータ、およびWeb閲覧のみ許可されている重要資料について、その理由・利用条件・取得手順・想定費用をまとめたものである。

## 3. 主要保留データの取得手順・申請要領

### 3.1 国土地理院 旧版地形図（明治〜昭和戦前期）の入手手順

国土地理院が所蔵する旧版地形図（5万分の1、2万5千分の1）は、現在の地図から抹消された神社・祠記号、旧道、消滅集落の存在を確認するための最重要一級資料である。

1. **Web閲覧サービス（無料）**:
   - システム: 国土地理院「地図・空中写真閲覧サービス」（`https://service.gsi.go.jp/map-photos/app/`）
   - 条件: Webブラウザ画面上での目視確認は無料。ただし、最高画質の一括保存やスクレイピングは規約により不可。
2. **謄本交付申請（高精細データ・公的原本）**:
   - 申請先: 一般財団法人 日本地図センター（国土地理院委託窓口）または国土地理院情報サービス館
   - 申請方法: オンライン申請（地図センターWebサイト）または郵送申請
   - 交付形態: 複製物（高精細TIFFデータ / プリント用紙）
   - 費用: 電子データ交付 1面あたり約400円〜1,000円程度（図幅・解像度により異なる）
   - 対象主要図幅（津久井・相模原および隣接地域）:
     - 5万分の1: 「八王子」「上野原」「御殿場」「小田原」「東京西南部」
     - 2万5千分の1: 「青野原」「相模湖」「城山」「中津川」「八王子」等

### 3.2 国土地理院 基盤地図情報 数値標高モデル（DEM 5m / 10m）

1. **提供内容**:
   - 5mメッシュ（DEM5A: 航空レーザ測量成果、DEM5B: 写真測量成果）
   - 10mメッシュ（DEM10B）
2. **利用条件**:
   - 国土地理院の「基盤地図情報ダウンロードサービス」（`https://service.gsi.go.jp/kiban/`）での無料ユーザー登録が必要。
   - 利用規約に同意し、私的利用または測量法に基づく利用申請が必要。
3. **Phase 1への推奨アクション**:
   - ユーザー側で無料アカウントを作成し、必要メッシュ（相模原市緑区周辺: 5339メッシュ区画）をダウンロードして Google Drive `raw/dem/` へ配置する。
   - 代替手段として、国土地理院標準の標高タイル（`https://cyberjapandata.gsi.go.jp/xyz/dem10b/{z}/{x}/{y}.txt`）をQGIS/Python上で動的参照する設計を採用可能。

### 3.3 今昔マップ on the web の利用規約遵守

- 提供元: 埼玉大学教育学部 谷謙二教授
- 規約内容: 「本サイトの画像データ等を自動取得ツール等により大量にダウンロードすること、およびローカル環境へキャッシュ・保存して再配布・外部解析にかけることは禁止されています。」
- プロジェクト方針:
  - サイト画像ファイルの直接保存・スクレイピングは**一切行わない**。
  - 論文（谷2017: 今昔マップの開発と公開）を `literature/papers/Tani2017_KonjakuMap.pdf` として取得・読解し、その座標変換アルゴリズム・時系列比較手法をシステム設計の参考とする。

### 3.4 歴史資料・公文書館所蔵「神社明細帳」

- 背景: 明治39年（1906年）の「神社合祀令」以前に存在した無格社・小祠・境内末社は、公文書館所蔵の『神社明細帳』『皇国地誌』『新編相模国風土記稿』にのみ記載されているケースが多い。
- 状況:
  - 『新編相模国風土記稿 第5輯 三浦・津久井郡』は国会図書館IIIFマニフェスト（`Shinpen_Sagami_Fudokiko_Vol5_IIIF_manifest.json`）を取得済み。
  - 各町村の明治期『神社明細帳』原本は、神奈川県立公文書館（公文書館刊行目録 `rekishishiryoushozaimokuroku14-4-1.pdf` 取得済み）に所蔵されており、現地閲覧複写申請が必要となる。

### 3.5 国土地理院 過去航空写真・空中写真の提供実態と入手方針

1. **地理院タイル（Web動的参照・無償）**:
   - URL形式: `https://cyberjapandata.gsi.go.jp/xyz/{layer}/{z}/{x}/{y}.jpg`
   - 主な対象レイヤー:
     - `seamlessphoto` (最新全国シームレス写真)
     - `gazo1` (1974年〜1978年撮影写真)
     - `ort_old10` (1961年〜1969年撮影写真)
     - `ort_USA10` (1945年〜1950年 米軍撮影写真)
   - 利用実態: WebブラウザやQGISからの動的ストリーミング参照は無料・申請不要。ただし、全域のタイル画像ファイルを一括スクレイピング・ローカル保存することはサーバ負荷防止および規約上推奨されない。

2. **地図・空中写真閲覧サービス（単写真の無料ダウンロード）**:
   - システム: 国土地理院「地図・空中写真閲覧サービス」（`https://mapps.gsi.go.jp/`）
   - **無料ダウンロード対象**:
     - 1936年頃（旧陸軍撮影）、1940年代（米軍撮影）、1960〜1970年代（国土地理院撮影）などの単写真ネガフィルムスキャン画像（400dpi / 800dpi JPEG/TIFF）は、コース・写真番号ごとに個別に検索し、**無償でダウンロード可能**（出典明記要）。
     - **技術的留意事項**: これらは正射変換されていない「単写真（中心投影）」であるため、GIS上で地図と正確に重ねるには、数値標高モデル（DEM）と地上基準点（GCP）を用いた幾何補正（オルソ化・ジオレファレンス）が必要となる。
   - **有料交付対象**:
     - 最新の高解像度デジタルオルソ画像原本や、測量成果としてのTIFFデータ交付は、日本地図センターを通じた有償申請が必要。

3. **本プロジェクトの方針**:
   - 現時点（Phase 0.3）ではデータバンク上に航空写真画像原本は保存されていないため、カバレッジ表では誠実に**「未取得」**と表記。
   - Phase 1において、初期対象地区（青野原・鳥屋・青山・寸沢嵐）のピンポイントな座標範囲に絞り、国土地理院閲覧サービスから1940年代米軍写真および1960〜70年代空中写真の無償単写真を手動検索・選定ダウンロードし、オルソ補正処理を適用する。
