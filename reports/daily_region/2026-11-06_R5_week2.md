## 2. 周知の事実

期間の違う事実を、2014→2021 年の土地利用変化の原因にはしない。

1. 相模原市は 2010-04-01 に政令指定都市へ移行し、緑区・中央区・南区の3区になった。緑区は旧相模原市北部と旧津久井郡を含む。
   （神奈川県「県央地域県政総合センター」 https://www.pref.kanagawa.jp/docs/u5r/index.html 。ページの更新日は土地被覆の期間ではない）
2. 旧津久井郡は、津久井町・相模湖町が 2006-03-20、城山町・藤野町が 2007-03-11 に相模原市へ編入して消滅した。R5 はその旧郡域を除く。
   （相模原市の区のページ。編入日は土地利用調査年ではない）

## 3. 仮説

閾値は検証前に固定した。

### H1（週1宿題）: R6 の農地→森林と建物用地→森林は、率でも絶対量でも R5 より大きい

支持条件（すべて）:

- R6 の農地→森林率が R5 より大きい
- R6 の建物用地→森林・荒地率が R5 より大きい
- R6 の農地→森林の面積が R5 より大きい
- R6 の建物用地→森林の面積が R5 より大きい

率を比べてよいのは、農地と建物用地の基数がどちらも 0.5 km² 以上のときだけである。週1の丸め（0.38% と 2.4%、0.23% と 1.78%）は再確認であり、支持条件の本体は再計算値である。

### H2（週1宿題）: 建物用地の総減少のうち、森林と荒地へ向かう割合は 10% 未満である

支持条件:

- （建物用地→森林 + 建物用地→荒地）/ 建物用地総減少 が **10% 未満**

10% は週1の森林化判定と同じ桁の、結果を見る前の丸い閾値である。results.json に無い行き先の内訳は作らない。公開レポート §2 の「農地→建物用地 相模原 0.91 km²」は農地の行き先であり、建物用地の総減少の内訳ではない。判定には使わない。

### H3（前日の反省）: 週1の「5セル以上 28.6%」は 1〜2 セルの補集合であり、真の 5 セル以上は 20% 未満で、補集合との差は 10 ポイント以上ある

支持条件（すべて）:

- `share_>=5` が **20% 未満**
- （1 − share_1 − share_2）− share_>=5 が **10 ポイント以上**
- 建物用地→森林と農地→森林の `size_>=5_share` がどちらも **0**

20% は、週1が書いた 28.6% より下に真値があるかを見るための閾値である。28.6 を 14 に書き換えて支持にはしない。10 ポイントは R4 週2と同じ差の閾値である。

### H4（前日の反省）: 建物用地の純増を求める週1の条件は、R5 に完全に含まれる区の行でも満たされない

支持条件:

- 地域行の建物用地純変化が **負**
- 中央区と南区の建物用地純変化がどちらも **負**

緑区の区行は R5 の内訳ではないので、この条件に入れない。符号の閾値は週1のまま（純増なら都市的転換型の一条件を満たす）。R5 セルを区名で切った緑区 1,480 セルの純変化は、公開の区行ではないので支持条件に入れず、結果の限定として出す。

## 4. 結果

数値は `scripts/2026-11-06_R5_analysis.py` の出力と一致する。

### 4.1 H1 — 支持（率の倍率と面積の倍率は違う）

基数はすべて 0.5 km² 以上である。R5 の農地 8.341 km²、建物用地 63.922 km²。R6 の農地 12.170 km²、建物用地 16.516 km²。率の比較から外す類型は無い。

| 指標 | R5 | R6 | R6 − R5 |
|---|---:|---:|---:|
| 農地→森林率 | 0.377% | 2.409% | +2.033 pp |
| 農地→森林 | 0.0314 km² | 0.2932 km² | +0.2618 km² |
| 建物用地→森林・荒地率 | 0.230% | 1.775% | +1.546 pp |
| 建物用地→森林 | 0.1467 km² | 0.2932 km² | +0.1465 km² |
| 建物用地→荒地 | 0 | 0 | 0 |

4条件とも R6 が大きい。H1 は **支持** される。

読みの限定: 建物用地では、率は R6 が R5 の約 7.7 倍、面積は約 2.0 倍である。差が開くのは、R6 の建物用地基数 16.516 km² が R5 の 63.922 km² より小さいからである。率だけを「R6 は 8 倍森林化した」と書かない。農地→森林は、率で約 6.4 倍、面積で約 9.3 倍である。こちらは面積の倍率の方が大きい。

### 4.2 H2 — 支持（残差に行き先の名前は付けない）

| 建物用地 | 面積 | 総減少に占める割合 |
|---|---:|---:|
| 総減少 | 2.358 km² | 100% |
| →森林 | 0.147 km² | 6.22% |
| →荒地 | 0 | 0 |
| 上の合計 | 0.147 km² | 6.22% |
| 総増加 | 1.991 km² | — |
| 純変化 | −0.367 km² | — |
| 総減少から森林・荒地を引いた残差 | 2.211 km² | 93.78% |

6.22% は 10% 未満である。H2 は **支持** される。

残差 2.211 km² の内訳（その他の用地、交通用地、農地など）は region 列に無い。名前を割り当てない。公開レポート §2 の相模原列は、建物用地 63.92 km²、総減少 2.36 km²、総増加 1.99 km²、農地→森林・荒地 0.03 km²、農地→建物用地 0.91 km² である。0.91 km² は農地の行き先であり、2.211 km² の内訳ではない。

### 4.3 H3 — 支持

`component_class_share_by_region` の R5 行。変化陸域 5.459 km²。

| 成分 | シェア | 面積 |
|---|---:|---:|
| 1セル | 52.40% | 2.861 km² |
| 2セル | 19.00% | 1.037 km² |
| 1〜2セル | 71.40% | 3.898 km² |
| 3〜4セル | 14.97% | 0.817 km² |
| **5セル以上** | **13.62%** | **0.744 km²** |
| 1〜2セルの補集合 | 28.60% | 1.561 km² |

週1の「5セル以上 28.6%（1.56 km²）」は、この表の補集合である。真の 5 セル以上は 13.62%（0.744 km²）である。補集合との差は 14.97 ポイントで、3〜4 セルのシェアそのものに等しい。

建物用地→森林（14 セル）と農地→森林（3 セル）の `size_>=5_share` はどちらも 0、最大成分はどちらも 1 セルである。

3条件を満たす。H3 は **支持** される。変化全体の 0.744 km² の用途内訳は、地域×from の成分表が無いので推定しない。焦点の二つの遷移に 5 セル以上は無い、という週1の H3 は再確認でも残る。

### 4.4 H4 — 支持（緑区の区行は条件に入れない）

| 行 | 建物用地の純変化 | この行は R5 か |
|---|---:|---|
| R5 地域行 | −0.367 km² | はい |
| 中央区の区行 | −0.147 km² | はい（区の全体が R5） |
| 南区の区行 | −0.115 km² | はい（区の全体が R5） |
| 緑区の区行 | +0.597 km² | いいえ（R6 を含む） |

地域行・中央区・南区はどれも純増ではない。H4 は **支持** される。都市的転換型の「建物用地が純増」は、R5 に完全に含まれる公開の区行でも満たされない。

緑区の区行のプラスは、R5 の棄却をひっくり返す材料にしない。R5 セルのうち緑区に落ちる 1,480 セル（建物用地 2014 年 11.248 km²）の純変化は **−0.105 km²** である。これは公開の区行ではなく、セル面積の合計である。地域行 −0.367 km² は、中央 −0.147、南 −0.115、この緑区スライス −0.105 の合計と一致する。3つとも負である。類型には分けていない。

## 5. 消失候補の探索

採用は **0 件**（高 0、中 0、低 0）。神社としての採用も 0 である。特別回で神社が 0 件だったあと、旧版の鳥居記号を優先する方針にしたが、旧版ラスタはこの添付に無く、今昔マップと迅速測図のタイル一括取得は `data/raw/historical_maps/README.md` に従って行っていない。高確度は付けていない。

行った照合は次のとおり。

1. **現行の地理院注記（個別）。** 建物用地→森林 14 セルと農地→森林 3 セルの重心が落ちるズーム 15 の `experimental_anno` タイルは 12 枚で、12 枚とも取得できた（2026-11-06、国土地理院コンテンツ利用規約）。セルと交差する注記に「神社」「寺院」「鳥居」を含むものは **0 セル** だった。このレイヤは注記文字であり、同じ系列のタイルには町字名（ftCode 0210）が出る。0 セルは、鳥居記号が地形図に無いことの証明ではない。旧版との差でもない。
2. **現行 OSM の礼拝施設。** 2026-11-05 に取得した関東抽出（ODbL、2026-11-04）を R5 セルで切ると **137 件** がセル内にある。これは現存側の対照であり、欠落を候補にはしていない。
3. **相模原市文化財 CSV。** `bunkazai.csv` は 179 行で、緯度の列はすべて空だった。R5 への点の内包は 0 である。住所から座標は作っていない。
4. **Wikidata の終了日（2026-11-05 取得、CC0）。** 行政合併 221 件は候補にしていない。R5 セルに入り、鉄道または礼拝の同じ語幹が 2026 年の OSM に 400 m 以内で残っていたものが 1 件あった。現行の地図名称が残っているので不採用にした。名称は非公開資料にだけ書いた。

したがって、今日の R5 では「地図から消えた神社」を、座標付きで採用できる資料が無かった。

## 6. 考察

1. R6 は R5 より、農地→森林も建物用地→森林も、率と面積の両方で大きい。週1の対比は再計算でも残る。建物用地の率の倍率は、基数の小ささが作っている。
2. 建物用地の純減 −0.367 km² の大部分は、森林でも荒地でもない残差 2.211 km² から総増加 1.991 km² を引いた結果である。残差の用途は不明のままである。
3. 5 セル以上は変化陸域の 13.62%（0.744 km²）である。28.60%（1.561 km²）は 3 セル以上である。焦点遷移のパッチは、今週も無い。
4. 緑区の区行が建物用地の純増でも、R5 に属する緑区のセルは純減である。市や区の1行で R5 を代表しない、という週1の結論は、符号の向きでも残る。
5. 消失候補は 0 件である。現行注記の個別確認は、旧版の鳥居記号の代わりにはならなかった。

## 7. 反省

1. 文化財 CSV に緯度列があることを、空でないことを確認する前に対照だとみなした。179 行すべて空だった。次回は列の非空件数を先に書く。
2. 終了日のある駅を、礼拝施設との名称照合だけで「地図から消えた」にしない。鉄道の名称レイヤを同じ距離で見る。今日、R5 セル内の 1 件はそこで落ちた。
3. 注記タイルの「神社」0 件を、鳥居記号の不在と書かない。レイヤの中身（町字名が出る）を先に書く。

## 8. 来週（7日後、2026-11-13）の R5（3週目）への申し送り

経過日数 18 なら `floor(18/7)+1 = 3`、`18 mod 7 = 4` で再び R5 である。着手時に README の式で計算し直す。

1. **5セル以上。** 13.62%（0.744 km²）が 5 セル以上、28.60%（1.561 km²）が 3 セル以上である。28.6% を 5 セル以上として再掲しない。焦点遷移の 5 セル以上は 0 のまま再確認する。閾値 20% と 10 ポイントは動かさない。
2. **緑区の区行。** +0.597 km² は R5 の内訳ではない。R5 セルの緑区 1,480 は −0.105 km² である。区行のプラスだけを書かない。類型は地域全体のまま、区へ割り振らない。
3. **建物用地の残差。** 2.211 km² に用途名を付けない。公開表の農地→建物用地 0.91 km² を、この残差へ割り当てない。
4. **候補探索。** 採用 ID は無い。次に見る範囲は、建物用地→森林 14 セルと農地→森林 3 セルに限る。旧版地形図は正規の交付でそのセルだけを見る。今昔マップと迅速測図のタイルは保存しない。文化財 CSV は緯度が空でない版が来るまで、座標の対照に使わない。住所のジオコーディングはしない。OSM の place 欠落は使わない。
