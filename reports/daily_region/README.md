# 地域別デイリー分析（R1〜R7 循環）

ユーザーの明示指示（2026-10-26）により開始した、継続分析シリーズ。
成果物はすべてこのブランチ `analysis/daily-region-cycle` に集約する（main へは push しない）。

## ローテーション

- 開始日 2026-10-26 を Day 1 とし、毎日1地域を対象にする。
- 順番は R1 → R2 → R3 → R4 → R5 → R6 → R7 → R1 → …（7日で一周、8日目が次の週の R1）。
- 地域の定義は `config/phase1c2_regions.toml` の R1〜R7 に従う。
  - R1 横浜・川崎 / R2 三浦半島 / R3 湘南 / R4 県央（相模原市を除く） /
    R5 相模原（旧津久井郡を除く） / R6 津久井（旧津久井郡4町） / R7 県西
- 週数は `floor((経過日数) / 7) + 1`、週内の地域は `経過日数 mod 7` で決める。

## 各回の構成

### 2026-11-10から（改訂方針）

ユーザー指示（2026-11-09、適用は2026-11-10）により、主目的は神奈川県内の廃神社・廃寺・消滅集落・廃道・廃施設の探索と検証である。土地利用分析は、候補の探索か検証に役立つときだけ行う。新規が無い日も、探索範囲・不採用の理由・未確認を書く。

1. 対象地域を決める（下のローテーション）。
2. 前回の同地域と、前日の反省と、既存の候補DBを読む。
3. まだ見ていない資料・地物の種類から候補を探す。
4. 既存候補は、新しい証拠があるときだけ再検証する。
5. 必要ならGIS・統計を使う。
6. 非公開の候補DBと、公開レポートに残す。候補は新規・既存・再検証・棄却と安定IDで管理し、棄却も残す。IDは再利用しない。
7. 評価は3軸に分ける。過去に存在した根拠、廃止・消失の根拠、物理的遺構が今も残る可能性。種別（駅、神社、寺院、集落、施設、廃道）を混ぜない。OSMに名称が無いことや、森林化したことだけでは消失にしない。
8. 7日ごとに、増減・種別・根拠の強さ・重複・棄却・未確認を集計する。候補が増えても根拠が弱くなれば、探索の仕方を見直す。
9. 翌回への課題を書く。冒頭に「先週の同地域からの引き継ぎ」、末尾に「来週の同地域への申し送り」を置く。

公開してよいのは手法、市区町村単位の件数、確度と種別、限界、申し送り、候補IDと市区町村名、検証の手順である。正確な緯度経度、地点を特定できる名称、大字以下の住所、候補一覧CSV、DriveのフォルダIDとURLは、リポジトリとPRコメントに置かない。

### 2026-10-26から2026-11-09までの構成（履歴）

1. **現在分析できていること** — 対象地域についてリポジトリの既存成果（主に Phase 1-C2 v0.2.0 の
   集計、Phase 1-C1 の実施範囲）で言える範囲と、言えない範囲（網羅率・scope）を最初に固定する。
2. **周知の事実・地域の特徴** — 公的資料・報道などのウェブ検索で裏付け、出所 URL を残す。
3. **仮説** — 検証前に、支持／棄却の目安となる閾値を文章で明示する。
4. **分析** — リポジトリの集計データ（`reports/phase1c2_results.json` 等）を再計算して検証する。
   再計算スクリプトを `scripts/` に同梱し、レポートの数値はスクリプトで再現できるものだけを使う。
   ウェブで得た数値は出典と対象期間を明記し、期間の違うデータを因果でつながない。
5. **結果と考察** — 仮説の支持／棄却／保留を分け、廃墟調査（本プロジェクトの目的）への含意と
   限界（判読法の変更、1セル成分の多さ、重心帰属など）を書く。
6. **反省点** — 主に分析・調査の進め方について、翌日に引き継ぐ改善点を具体的に書く。

## 継続のルール

- **2日目以降**: 前日のレポートの「反省点」を最初に読み、少なくとも1つをその日の分析に反映し、
  反映した旨をレポートに明記する。
- **2週目以降**: 前日に加えて、先週の同地域レポートの「結果・考察」と「来週への宿題」を読み、
  先週の仮説の続編・再検証・未解決事項の引き継ぎを必ず1件以上行う。
- 反省の累積は `reflections_log.md` にも1行ずつ追記する（上書きしない）。
- **各回の push 後、その日のレポートの要約を PR #28 のコメントとして投稿する**（ユーザー指示 2026-10-26）。
  要約には対象地域と週、仮説と判定、核心の数値、反映した反省、レポートへのリンクを含める。

## 境界（フェーズゲートとの関係）

時期で分ける。あとの指示は、前の禁止をその範囲で置き換える。置き換わる前の文は消さない。

### 2026-11-05以前の制限（履歴）

- 本シリーズはユーザーの明示指示に基づく既存集計のオフライン分析であり、新規の GIS データ取得、Google Drive へのアクセス・台帳追記、Phase 1-D の実解析（候補地点の抽出・ランキング・位置公開）は行わない。
- 個別地点の座標や私有地候補は扱わない。使うのは地域・市区町村単位の公開済み集計のみ。
- 既存レポート・原本は上書きしない。成果物は `reports/daily_region/` 配下に新規追加する。

### 2026-11-05のユーザー指示による変更（履歴。2026-11-09までこの節が現行だった）

ユーザー指示（2026-11-05）により、直前の禁止（候補地点を出さない、座標を扱わない、新規取得をしない、Drive を読まない）は次の運用に置き換えた。

- 消失候補の直接探索を各回に含める。
- ユーザーの Drive データは読み取りだけに使う。台帳の原本は書き換えない。
- 公開データは新たに取得してよい。取得元 URL・取得日・ライセンスを記録する。
  旧版地図・今昔マップ・迅速測図のタイル一括取得は、Drive の
  `data/raw/historical_maps/README.md` の制約に従い行わない。
- 正確な緯度経度、地点を特定できる名称、大字以下の住所、候補一覧 CSV、
  その他公にすべきでない情報は、リポジトリに置かない。非公開の内部資料に記録する。
  リポジトリでは候補 ID と市区町村名だけを参照する。
- 新規取得した公開データの実体もリポジトリに置かない。
- 既存の過去レポートは上書きしない。成果物は `reports/daily_region/` 配下に新規追加する。
- main には push しない。PR #28 はマージしない。

### 2026-11-09のユーザー指示による変更（2026-11-10から適用）

- 7日周期と、公開しない情報の範囲（座標、地点を特定できる名称、大字以下、候補一覧、DriveのフォルダIDとURL）は維持する。
- 主目的を、廃神社・廃寺・消滅集落・廃道・廃施設の探索と検証に移す。土地利用は、その探索か検証に役立つ場合に限る。
- データの種類は問わない。文献、歴史的地名、今昔マップ、地理院の旧版地図、迅速測図、空中写真、自治体・神社庁・郷土史、個人サイト、動画の字幕・説明文・メタデータを取得してよい。古地図と空中写真のタイルは、焦点とその周辺に限る。各サイトの利用条件と出典を残す。取得していないものを取得済みと書かない。
- この許可はデータ取得についてのものであり、Phase 1-Dの全面実行や、ほかの未承認作業を含まない。
- 候補は3軸で評価し、種別を分け、安定IDで残す。棄却も残す。原本の台帳は変えない。
- PR #28 は Draft のままにする。main には push しない。
