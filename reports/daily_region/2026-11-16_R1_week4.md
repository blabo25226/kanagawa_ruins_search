## 5. 考察

1. 週3の土地利用の数は、セルで再現した。候補の探索には使っていない。近い二つの数（5.193 と 6.555、4.373 と 4.362、9.632 と 21.108）は、種類が違うので等しくしていない。
2. 廃社は 0 のままである。震災誌は、存在の強い一覧にはなる。廃止の一覧にはならない。現社と確認できた焼失・崩壊は負例にし、頁が遷座や合祀と書くものだけを状態変化にした。
3. 保留 8 件は、総括に名があり、現存も廃絶も閉じていない。検索 0 件では棄却しない。

5. 行は 24 から 65 へ増えた。増分は負例、状態変化、保留、棄却である。根拠が中より上に増えたわけではない。

## 6. 反省

1. 注記の語幹は、タイル全体の部分一致にすると居住地名を巻き込む。前回と同じく、居住地名と行政区画を除き、200 m の完全一致だけにした。当たりは 0 である。
2. 総括の「十六」と名指しの 14 を、個別表で埋めたくなった。埋めなかった。次も、名指しに無い件数は欠番のままにする。

4. 空中写真を取得したことと、遺構を確認したことを分けて書いた。38 枚は未読の地形であり、記号の照合ではない。

## 7. 来週（2026-11-23）の R1（5週目）への申し送り

経過日数 28 なら `floor(28 / 7) + 1 = 5`、`28 mod 7 = 0` で再び R1 である。着手時に README の式で計算し直す。

1. **その他。** 純増は +5.193 km²。総流入 10.268 km² から総流出 5.075 km² を引いた差である。6.555 km² を純増と呼ばない。
2. **森林。** 純変化は −4.373 km²、総流出は 6.847 km²、森林→建物用地は 4.362 km²、建物用地以外は 2.485 km²（その他 1.133、農地 0.881、交通用地 0.294、ゴルフ場 0.136、荒地 0.042）である。差 0.011 km² を一致の証拠にしない。
3. **都筑区。** 面積シェアは都市的 70.0%、農地混在 30.0%。セル純増は +7 と +3。増加と減少を分けた数は、都市的が 17 と 10、農地混在が 7 と 4 である。他類型は 0 である。
4. **川崎区。** 建物用地総減少 1.488 km² の 81.7% はその他、16.2% は交通用地、森林と荒地は 0 である。候補の絞り込みに使わない。
5. **5セル以上。** 9.632% が 5セル以上、21.108% が 3セル以上である。焦点の 5セル以上は 0 のままである。
6. **候補。** 再検証 24 は中のまま。廃社の採用は 0、高は 0。次に見るのは、保留 8 件（R1-027、R1-030、R1-035、R1-037、R1-039、R1-041、R1-042、R1-043）の現存か廃絶かである。総括の残り 2 社は、個別表から埋めない。注記の失敗は焦点 15 セルと R1-017 のままである。旧版地形図は未取得のままである。投稿の保留 4 件（R1-059、R1-061、R1-064、R1-065）は、公的な廃止記録が無い。リード2の現社は、神社庁の検索が 0 件のままで、存在は中である。0 件を不在にしない。現行の礼拝施設 1,304 件は、今日再抽出していない対照の母数である。
