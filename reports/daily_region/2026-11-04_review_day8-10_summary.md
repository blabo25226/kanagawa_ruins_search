## 1. レビュー方法

1. `reports/daily_region/README.md` の固定構成（現在分析できていること、周知の事実、仮説、分析、結果と考察、反省点）、継続のルール（前日の反省、2週目は先週の同地域の結果・考察・宿題、閾値は検証前、率には絶対量と基数、総流入と純変化を分ける、ウェブには URL と対象期間、期間の違うデータを因果でつながない）、`reflections_log.md` とインデックスの更新、を各回の本文に当てた。
2. 各回の再計算スクリプトを、この作業ツリーで実行した。終了コードは 3 本とも 0 である。本文の判定に使われている数値を、スクリプト出力の未丸め値および、スクリプトが印字しない項目については同じ JSON の該当表と照合した。
3. 統計的主張は、事前に置いた閾値との比較と、標本サイズに見合う読み方（同順位の扱い、有意と言っているか）の両方で見た。
4. 結論を左右しない書式の揺れは、重大度を付けて記録するに留め、追補の対象にはしていない。

## 6. 1週目から 2週目までの知見

同じ v0.2.0（2014→2021 年）を 2 周した。新しい変化の観測は増えていない。増えたのは、地域行をそのまま地域の姿と読まないための限定である。

- 網羅がほぼ全域なのは R1（98.9%・comparable）である。R1 の 2週目は、森林純減と農地純減が区の単位では重なり弱く（3/6 区、スピアマン 0.26）、都市的メッシュの中では両方の純減の約 4 分の 3 が起きている、と分けた。建物用地は地域では純増でも、川崎区は churn（総減少率 6.45%、純 −0.69 km²）、保土ケ谷区は増加（純 +0.72 km²）である。
- R2 は 2週目も「三浦半島の値」ではない。収録は鎌倉市北部 15.32 km²（7.4%）で、その中の変化面積の 80.0% が都市的メッシュである。P32 の地域別バッファ値はどの地域にも無く、地点数 3 は R5 と共通なので、地点数の少なさだけでは比較除外の理由にならない。
- R3 は収録 83.4% の参考値である。2週目は、農地純減少は内陸 2 市（64.4%、率は沿岸の 2.22 倍）、建物用地の純増は沿岸 3 市（60.3%）と、指標ごとに群が入れ替わることを出した。追補により、この内陸シェアは類型へは帰属できず、変化面積も単一類型が 50% を超えない。
- 1週目の R4〜R7 と合わせると、comparable で農地純減率が最大なのは R1（−13.1%）であり、R7 の収録範囲だけが農地純増である。森林の絶対減が最大なのも R1（−4.37 km²）で、森林化率の高さは R6・R7 側にある。総流入の率と純変化の符号は、R1・R2・R3 の森林でいずれも逆向きになりうる。
- 廃墟候補の絞り込みに使えるまとまったパッチは、この 3 回の focus 遷移には無かった。R1 の最大成分は 3 セル、R3 は 2 セル、5 セル以上シェアはどちらも 0 である。R2 の変化は 55 セル規模で、1 セル成分が過半である。

## 7. 2026-11-05 R4 週2以降への改善

土台は 1週目の [2026-10-29_R4_week1.md](2026-10-29_R4_week1.md) である。地域平均は南部の都市的な値と北部の森林的な値の合成であり、農地減少は都市的転換型だが森林化側へ 1 セル未満の余裕しか無い、という結論と、§8 の 3 群比較（南部 4 市・北部 2 町村・厚木市）が翌日の主軸になる。直近の申し送りは R3 週2の反省（群シェアの比較相手を仮説の段階で固定する、導出値は列名と表の直下に式を書く、基数条件は棚卸しで確認する、冒頭で系列の欠落を見る）と、本レビューの追補（クロス集計が無い帰属は保留、50% の直下で閾値を動かさない）である。

1. 作業の最初に `git log -1` と、暦の前日のファイルの有無を両方見る。ファイルが作業開始時に無くても、コミット時に親が前日の回になっているなら、本文の「不在」を残したまま積まない。backfill する回は、名義の日付と commit 日付の差を冒頭に 1 行書く。
2. 先週の同地域レポートを土台にする節を、仮説より前に置く。1週目のどの数値を再検証するのか（R4 なら厚木市への集中、森林・荒地へ 9.8%、建物用地純増 +1.29 km²、二極のレンジ）を、値と節番号つきで書く。1週目 §8 は既に「来週への宿題」がある。2週目はその宿題への回答を、同じ番号で対応づける。
3. 1週目 R4 の「5 セル以上の成分は 22.7%（2.86 km²）」は、引き継ぐ前に再計算する。`component_class_share_by_region` の R4 行は、1 セル 55.10%（6.96 km²）、1〜2 セル合計 77.34%（9.78 km²）、3〜4 セル 13.11%、5 セル以上 9.54%（1.21 km²）である。22.7% と 2.86 km² は 1〜2 セルの補集合で、3 セル以上のシェアである。5 セル以上ではない。2週目の本文にこの 22.7% を 5 セル以上として再掲しない。
4. 1週目 §8 の「厚木市の農地→森林 0.30 km² の類型別内訳」は、市区町村×類型のクロス表が JSON に無い。R3 追補の H-A と同じで、無いものは保留とし、地域×類型の行を厚木市の内訳として読まない。
5. 群シェアの比較相手（収録面積シェアか、その指標の基数シェアか）を仮説の文に書く。R3 で 43.8% が面積シェアとの比較と基数シェアとの比較で意味が変わった、という反省を R4 の 3 群で先に使う。
6. 1週目に既出の割合より緩い閾値だけを支持条件にしない。既出の確認は「再確認」と書き、新しい条件（率、総増加、別指標）を支持の本体にする。閾値ギリギリの R4 は、1週目の反省どおり余裕を km² とセル数で残す。
7. 順位相関を使うときは平均順位で同順位を処理し、n と、有意と言わないことを書く。棄却の根拠は事前の実質閾値に置く。R1 の 0.26 は有意ではなく、事前の 0.5 にも届かない、という二段で書くと読みがぶれない。
