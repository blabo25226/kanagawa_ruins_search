## 前日の反省の反映

前日（2026-10-29、R4）の「反省点」5件を、以下のように本日の分析設計に反映した。

1. **comparable 地域でも、最初に市町村の建物・森林率の範囲（最大−最小）を出す。**
   → R5 ではその手順の**前提検証を先に行った**ところ、前提そのものが崩れた。
   区行の合計（31,401セル・328.96 km²）は R5 地域行（8,646セル・90.59 km²）と一致せず、
   緑区行が R6（旧津久井郡）を含む区全体の行であることが判明した。
   そのため区行の範囲は出さず、代わりに §1 冒頭の「集計単位の対応表」と
   R5／R6 対比を先に置き、すべての数値を「都市核の値」として読む枠組みに固定した。
   R4 の手順を無検証で転用しなかったこと自体が、今回の最大の反省の反映である。
2. **閾値ギリギリの判定は「支持（境界付近）」と明記し、感度を併記する。**
   → R5 の H2 は境界付近ではなく、建物用地の純変化が −0.37 km² と明確にマイナスで
   棄却となった。棄却の強さを示すため、総減少 2.36 km² と総増加 1.99 km² の差
   0.37 km²（35セル）を併記し、「あと何セルで反転するか」が読める形にした。
   また H2 の棄却と「森林化型であること」は別であることを判定表に明記した。
3. **農地→建物用地が results.json にない場合、公開表の補助引用に留め、判定には使わないと明記する。**
   → §4 の棚卸し表と §5 の注記の両方にその扱いを書いた。
   公開レポート §2 の面積表によれば農地→建物用地は相模原で 0.91 km² であるが、
   仮説の判定には使っていない。
4. **群合計は市町村行の合計で作り、地域平均と並べて示す。**
   → R5 では区行の合計が地域行にならないため、この手順は使えない。
   代わりに R5＋R6 の合計（= 区行合計）を作り、市全体との対比として示した。
   中央区・南区の合計（75.09 km²）は R5 の部分集合としてのみ使い、
   緑区行を加えて「R5 の内訳」とすることはしていない。
5. **P32 の地点数は、網羅率と並べて読む。**
   → R5 の P32 利用可能地点は 3 地点（108地点中）で、網羅率 100%・comparable の

   R4 と同じであり、地点数の多寡を文化財の多寡と読み替えない注意は

## 1. 現在分析できていること（R5）

### 1.1 まず結論：R5 については、地域全体の値として語れる集計が存在する。ただしそれは「相模原市」の値ではない

- **網羅率 100%**、scope は `comparable`。公開レポート §1 の地域表によれば、
  相模原（旧津久井郡を除く）は陸域 90.6 km²・100%、津久井は 238.4 km²・100% である。
- ただし §1.2 の通り、R5 は市面積の 27.5%（90.59 / 328.96 km²）に過ぎない都市核であり、

  消してしまう。R5 の値を使うときは、必ず「旧津久井郡を除く都市核の値」と断って読むこと。

## 2. 周知の事実・地域の特徴（ウェブ検索による裏付け）

すべて対象期間を併記する。期間の異なる事実同士を因果でつながない。
また「相模原市」の一般名と、本プロジェクトの R5 定義
（中央区・南区＋緑区旧市域）は別物であることに注意する。

1. **相模原市は 2010年4月1日に政令指定都市へ移行し、緑区・中央区・南区の3区制となった。**
   （出典: Wikipedia「相模原市」「緑区 (相模原市)」、
   https://ja.wikipedia.org/wiki/%E7%9B%B8%E6%A8%A1%E5%8E%9F%E5%B8%82?oldid=63387448 、
   http://ja.wikipedia.org/wiki/緑区_(相模原市) ）
   旧津久井郡 4 町は、津久井町・相模湖町が 2006年3月20日に、
   城山町・藤野町が 2007年3月11日に相模市へ編入され、津久井郡は消滅した。
   2010年の区制施行と同時に、旧郡域は全域が旧市域北部の橋本地区・大沢地区とともに
   緑区となった（出典: Wikipedia「津久井郡」、
   http://ja.wikipedia.org/wiki/津久井郡 ）。
   すなわち現在の緑区は、R5（旧市域部分）と R6（旧郡域）の両方を含む区であり、
   区単位の統計は R5／R6 の分割と対応しない。これが §1.2 の集計単位の罠の行政的な理由である。
2. **2025年9月1日現在の推計人口では、中央区 272,867人（36.87 km²）、
   南区 282,733人（38.11 km²）、緑区 166,170人（253.93 km²）、市合計 721,770人（328.91 km²）である。**
   （出典: Wikipedia「相模原市」の行政区の人口・面積表、
   https://ja.wikipedia.org/wiki/%E7%9B%B8%E6%A8%A1%E5%8E%9F%E5%B8%82?oldid=63387448 ）
   中央区・南区だけで市人口の 77.0%（555,600 / 721,770人）を占める一方、
   その面積は市面積の 22.8%（74.98 / 328.91 km²）に過ぎない。
   対象期間は 2025年推計であり、2014→2021年の土地利用変化の原因としては使わない。
   ここでの要点は、R5 の陸域が市面積の 27.5% に過ぎないのに対し、
   その中に市の人口の過半が集中する都市核が含まれること、すなわち
   R5 は「面積では小さいが人口では大きい」地域だということである。
   面積ベースの地域平均は、市の姿をそのまま表さない。
3. **R5 と R6 の対比は、C2 集計自体が示す事実である。**
   R5 の建物用地率 70.6%・森林率 4.8% に対し、R6 は建物用地率 6.9%・森林率 80.2% である。
   同じ市の分割でありながら、土地被覆の姿はほぼ反転している。
   この対比は、R5 の値を市全体の値として読んではならないことの、集計上の証拠である。

## 3. 仮説

### H1（主仮説）: R5 の値は相模原市全体の値ではなく、中央・南区＋緑区旧市域という都市核の値である

検証前に置いた支持条件（すべて満たせば支持）:

- R5 地域行の陸域（90.59 km²）が区行合計（328.96 km²）と一致せず、
  その差が R6 の陸域（238.38 km²）と 0.1 km² 以内で一致すること
- R5 の建物用地率（2014年）と緑区行の建物用地率の差が **50ポイント超**であること
- R5 と R6 の建物用地率の差と森林率の差が、いずれも **50ポイント超**であること

背景: R4 では区行合計 = 地域行が成立し、地域平均の問題は「内部のばらつき」だった。
R5 では区行合計 ≠ 地域行であり、問題は「集計単位の取り違え」である。
H1 は、R5 の値が市全体の値として誤読される危険を、数値で検証する。

### H2（副仮説）: R5 の農地減少は、森林化・荒地化型ではなく都市的転換型である

検証前に置いた支持条件（すべて満たせば支持。R1・R3・R4 と同じ閾値で比較可能にする）:

- 農地総減少に占める農地→森林・荒地の割合が **10% 未満**であること
- 建物用地の純変化が **プラス**であること
- 農地→森林率が **2% 未満**であること

背景: R1（横浜・川崎）・R3（湘南の収録範囲内）・R4（県央）では同じ型が確認されている
（R4 は境界付近）。R5 は建物用地率 70.6% と最も都市的であり、
農地の森林化は起きにくいと予想される一方、建物用地の純変化の符号は事前には不明である。
H2 はその読みを数値で検証する。なお 3 条件のうち 1 条件でも外れれば H2 は棄却とし、
棄却と「森林化型であること」は別の判定であることを明記する。

### H3（副仮説・廃墟調査への含意）: R5 では、建物用地→森林・荒地および
### 農地→森林の遷移は、まとまったパッチとして存在しない

検証前に置いた支持条件（すべて満たせば支持）:

- 建物用地→森林と農地→森林の両方で、最大の成分が **5セル未満**であること
- 両方の遷移で、5セル以上の成分の割合が **0%** であること

背景: 本プロジェクトの廃墟探索ロジックは、建物用地→森林・荒地遷移を痕跡とみる型である。
遷移がすべて 1 セルの孤立成分であれば、判読ノイズと実変化を区別できず、
探索の手がかりとしては使えない。H3 はその可否を判定する。
なお focus_by_region の成分構造は地域全体のものであり、類型別・区別の
成分構造は results.json にないため、類型別の率からパッチの有無は推論しない。

## 4. 分析方法と棚卸し

- `phase1c2_results.json` の coverage / region / municipality / region_landscape /
  transitions（focus_by_region）集計を再計算。1セル = 0.0105 km²。
- 地域行と区行合計の不一致、R5＋R6 = 区行合計、類型別内訳の合計をスクリプトのアサーションで検証した。

### 棚卸し：使う数値が機械可読な一次集計にあるか

| 使いたい数値 | results.json にあるか | 扱い |
|---|---|---|
| R5 の網羅率・scope | region 集計にあり（100%・comparable）。coverage.by_region の R5 行は市全体相当（328.87 km²）で R6 行なし | coverage 表の R5 行は R5 単独の値として使わない。網羅率は公開レポート §1 の地域表と region 集計に基づく |
| R5 の地域集計（構成・純変化・遷移） | あり（aggregates.region の R5 行） | 地域全体の値として使う（ただし H1 の通り都市核の値という注記つき） |
| 相模原市 3 区の区行 | 3 行あり、すべて網羅率 100%・comparable。ただし緑区行は R6 を含む | R5 の内訳として使わない。参考としてのみ掲げ、緑区行は R5 の値として読まない |
| 緑区内 R5 部分の集計 | なし（差し引きで約 15.50 km²・1,480セルと求まるのみ） | 面積・セル数の差し引きに留め、構成・変化の内訳は推論しない |
| 農地→建物用地（R5） | なし（region 集計に列がない） | 公開レポート §2 の面積表（相模原 0.91 km²）からの補助引用に留め、仮説の判定には使わない |
| R5 の類型別内訳 | あり（region_landscape の R5 行 4 類型） | そのまま使う。ただし森林卓越は 13セル・0.14 km² で基数 0.5 km² 未満のため順位付けに使わない |
| P32 の地域別内訳 | 地点数（R5 = 3）のみ | R5 限定のバッファ集計はないため、地点数と網羅率を並べて読むに留める |

## 5. 結果

### H1 の検証 — 支持

3条件すべてを満たしたため、H1 は **支持** される。
R5 の値（建物用地 70.6%・森林 4.8%）は、相模原市全体の姿ではない。
市全体の建物用地は、区行合計でも地域行合計（R5＋R6）でも 80.44 km² で一致し、
市面積 328.96 km² に対する割合は 24.5% である。
R5 の 70.6% は市全体の値とは桁違いであり、
「相模原市の建物用地率は 70.6%」という引用は誤りである。

| 農地総減少に占める農地→森林・荒地が 10% 未満 | **2.3%**（0.03 / 1.38 km²） | 満たす |
| 建物用地の純変化がプラス | **−0.37 km²**（−0.57%、総減少 2.36 km² ＞ 総増加 1.99 km²、差 35セル） | 満たさない |
| 農地→森林率が 2% 未満 | **0.38%**（0.03 / 8.34 km²） | 満たす |

3条件のうち 1 条件を満たさないため、H2 は **棄却** される。
ただしこれは「森林化型である」ことを意味しない。農地→森林・荒地は
農地総減少の 2.3% に過ぎず、森林化型の対立仮説も支持されない。
補助的な参考として、公開レポート §2 の面積表によれば農地→建物用地は相模原で 0.91 km² であり、
農地総減少 1.38 km² の 65.8% に当たる。ただしこの値は results.json の region 集計にはなく、
仮説の判定には使っていない（§4 の棚卸し参照）。
判定に使える範囲で言えるのは、「農地減少そのものは森林化型ではないが、
建物用地の純増を伴わないため、R1・R3・R4 と同じ意味での都市的転換型とも言えない」
という中間の結論である。R5 は、比較可能地域の中で初めて建物用地の純変化が
マイナスになった地域である（R1 +0.76%、R3 +3.04%、R4 +1.19%、R5 −0.57%）。
建物用地の総減少率 3.69% は R3（3.62%）・R4（3.06%）と同程度であり、
純減の理由は総減少の突出ではなく、総増加率 3.11% が総減少率を下回ったことにある。

  （区行合計 +0.34 km²）になるが、その内訳は R5 の純減と R6 の純増の相殺である。

### 5.3 変化の成分構造

分類が変化した陸域 5.46 km²（521セル）のうち、1セル成分が 52.4%（2.86 km²）、
1〜2セル成分が 71.4%（3.90 km²）である。5セル以上の成分は 28.6%（1.56 km²）に留まる。
変化の過半が孤立セルであるため、2021年の判読方法の変更と判読差ノイズの影響を
小さい遷移から切り分けることはできない。H2 の判定は、数十〜数百セル規模の
集計値（農地総減少 132セル、建物用地純変化 −35セル）に基づくものであり、
数セル規模の遷移の有無に基づくものではない。
建物用地→森林の 14セルがすべて境界上（100%）であることは、
境界付近の判読差が混ざりうることを示唆するが、results.json の範囲では
判読差と実変化の分離はできない。

## 6. 考察

1. **R5 の「100%」は、R4 の「100%」とは違う種類の問題を出す。**
   R4 は「区行合計 = 地域行」が成立し、問題は地域平均が内部のばらつきを隠すことだった。
   R5 は区行合計 ≠ 地域行であり、問題は集計単位そのものの取り違えである。
   comparable というラベルは、集計単位の対応までは保証しない。
   coverage 表の R5 行が市全体相当であることも含め、R5 では「何の 100% か」を
   最初に固定しないと、すべての後続の数値が誤読される。
2. **R5 の農地減少は、森林化型でも都市的転換型でもない中間の結論になる。**
   農地総減少 1.38 km² のうち森林・荒地へ向かったのは 2.3% であり、
   森林化型ではないことは明確である。しかし建物用地が純減しているため、
   R1・R3・R4 と同じ 3 条件の都市的転換型も成立しない。
   補助引用では農地→建物用地が 0.91 km²（総減少の 65.8%）であり、
   農地の行き先としては建物用地が主である可能性は高いが、
   それは判定外の補助情報であり、建物用地全体の純減と併せると
   「農地が建物用地に転換しても、建物用地全体は減っている」という
   一見矛盾した姿になる。行き先別の完全な内訳は results.json にないため、
   この矛盾の解消（他用途への転出か、判読変化か）は断定しない。
   2週目では、公開レポートの面積表・類型別表で建物用地の増減の内訳が
   補えるかを確認することが宿題になる。
3. **廃墟調査への含意は、R3・R4 と同じく「手がかりなし」であるが、理由が違う。**
   R3 では沿岸部の欠けが、R4 では孤立成分のみであることが理由だった。
   R5 では収録範囲に欠けはなく、遷移自体も建物用地→森林 14セル・農地→森林 3セルと
   極めて小さく、すべて 1 セル成分である。都市核では、建物用地の転換先は
   森林・荒地ではなく、その他・交通等の都市的用途に向かうとみられるが、
   その内訳は results.json の region 集計にはない。
   したがって C2 の集計から R5 の廃墟候補を絞り込むことはできない。
   なお R6（津久井）の建物用地→森林は 0.29 km²・率 1.78% と R5 より大きいが、
   それは明日の R6 の主題であり、R5 の値に混ぜてはならない。
4. **市単位の集計では、R5 の純減と R6 の純増が相殺される。**
   区行合計の建物用地純変化は +0.34 km²（緑区 +0.60、中央区 −0.15、南区 −0.12）であるが、
   これは R5 の −0.37 km² と R6 の +0.70 km² の相殺である。
   「相模原市の建物用地は純増」という市単位の言明は、都市核の純減を隠す。
   R5／R6 の分割は、分析上の区分である以上に、符号の反転を分離する意味を持つ。
5. **限界の明記。** 対象期間は 2014→2021年で、2021年には判読方法の変更がある。
   変化の 52.4% が1セル成分であり、小さい遷移は判読差ノイズを含みうる。
   セルは重心で市区町村・旧郡域に帰属しており、緑区内の R5／R6 境界付近のセルは
   CODH 2005-01-01 時点の旧行政界による帰属であり、現行の区界とは異なる。
   網羅率は面積ベースであり、人口・建物数ベースの網羅率ではない。
   2025年推計人口と 2014→2021年の土地利用変化は期間が重ならないため、
   因果の接続はしていない。P32 の地点数（R5 = 3）は、収録範囲の境界から 500 m 以上
   内側という選定条件の下での数であり、文化財の密度の証拠にはならない。

## 7. 反省点（翌日 R6 への引き継ぎ）

1. **区行合計＝地域行の検証を最初に行う。R5 では失敗し、R4 の群合計手順が転用できなかった。**
   今日はこの検証を先に行ったことで、緑区行を R5 の内訳として使う誤りを防げた。
   R6（緑区内旧郡域）でも区行は使えないため、R5／R6 対比と類型別を主軸にすること。
2. **coverage 表の地域行が市全体相当になる罠に注意する。**
   coverage.by_region に R6 行がなく、R5 行が市全体面積（328.87 km²）であった。
   R6 でも同じ罠が起きるため、網羅率は公開レポート §1 の地域表で確認すること。
3. **3 条件仮説で 1 条件だけ外れる場合、「棄却」と「対立仮説の支持」を分ける。**
   今日の H2 は棄却だが森林化型でもない。判定表に「対立仮説の判定」欄を加え、
   「どちらでもない」中間結論を二値に潰さないこと。
4. **基数 0.5 km² 未満の類型は、率そのものを本文の議論に使わない。**
   R5 の森林卓越メッシュは 13セル・0.14 km² であり、変化率 15.39% を含め
   順位付け・議論の材料にしなかった。R6 では森林卓越が主類型になるため、
   逆に「基数が大きい類型の率」として扱う切り替えが必要になる。
5. **P32 の地点数は、網羅率と並べて読む。**
   R5 は網羅率 100% で 3 地点である。地点数の多寡を文化財の多寡と読み替えない注意は、
   R6 でも繰り返すこと。

## 8. 来週の R5（2週目）への宿題

- R6 との対比を正式に行う。同じ市の分割として、農地→森林率（R5 0.38% vs R6 2.4%）と
  建物用地→森林・荒地率（R5 0.23% vs R6 1.78%）の差を、絶対量
  （農地→森林 0.03 vs 0.29 km²、建物用地→森林 0.15 vs 0.29 km²）とともに整理する。
- 建物用地純減の行き先について、公開レポートの面積表・類型別表で
  建物用地の総減少・総増加の内訳が補えるかを確認する。新たな推定や外挿は行わない。
- 緑区内 R5 部分（約 15.50 km²・1,480セル）の類型構成は region_landscape では
  分離できないため、R5 の類型表は地域全体のものとして扱い、
  区・旧郡域別の類型推論をしない範囲を維持する。
