## 3. 仮説

### H1（主仮説・2週目）: 収録範囲内の変化は都市的メッシュの変化が支配的である

検証前に置いた支持条件（すべて満たせば支持）:

- (a) 都市的メッシュの変化面積が、収録範囲全体の変化面積の **50%超**であること
- (b) 都市的メッシュの変化面積が、他の3類型の変化面積の合計を**上回る**こと
- (c) 都市的メッシュの建物用地純変化の符号が、地域全体の建物用地純変化の符号と**一致**すること

背景: 1週目は「収録範囲は鎌倉市北部のみ」という限定を面積・セル数で固定したが、
類型別の変化量までは掘っていなかった。もし都市的メッシュが変化の8割を占めるなら、
「R2 の変化」は実質「鎌倉市北部の都市部の変化」と言い換えるべきであり、
半島の農地・森林の動態として読むことは二重に誤りになる。
なおこの仮説は「収録範囲内の変化の地理的性格」についてのものであり、
変化量そのものが実変化か判読差か（1週目 H2 の保留）は本仮説では判定しない。

### H2（方法論ルール）: R2 を P32 バッファ比較の比較対象に入れてはならない

検証前に置いた支持条件（すべて満たせば支持）:

- (a) R2 限定のバッファ集計が results.json に**存在しない**こと
- (b) pooled バッファ集計の区分軸に**地域が含まれない**こと
- (c) 利用可能地点の選定そのものが**収録範囲に依存する構造**であること
  （1週目 §6.3 による、収録範囲の境界から 500 m 以上内側という選定条件）

背景: P32 の地点数（R2 = 3）だけを見ると「R2 は文化財が少ない」ように見えるが、
バッファ集計が地域別に分解できない以上、R2 の文化財周辺の土地利用を他地域と比較する
数値はそもそも存在しない。比較表に R2 の行を作ることは、存在しない数値の捏造に等しい。

## 4. 分析方法と棚卸し

- `phase1c2_results.json` の coverage / region / municipality / region_landscape / cultural 集計を再計算。
  1セル = 陸域 15.32 km² / 1,459セル = **0.0105 km²**。面積をセル数に換算して示す。
- 森林の流出量は直接の列がないため、純変化と流入量から算出した implied 値
  （流出 = 流入 − 純変化）として示す。同様に類型別の農地増加量は
  純変化 + 総減少量からの implied 値である。いずれも算出式を明記した上で使う。
- 検証（スクリプトのチェック項目）: 市区町村行の合計 = 地域行（15.32 km²、1,459セル）、
  類型別の変化量の合計 = 地域行の変化量（0.5777 km²）、類型別の建物用地純変化の合計 =
  地域行（+0.0525 km²）、類型別の農地純変化の合計 = 地域行（−0.000004 km²）。すべて一致した。

### 棚卸し：使う数値が機械可読な一次集計にあるか

| 使いたい数値 | results.json にあるか | 扱い |
|---|---|---|
| R2 の網羅率・収録面積・scope | あり（coverage） | そのまま使う |
| R2 の地域集計（構成・純変化・遷移） | あり（aggregates.region の R2 行） | ただし「鎌倉市北部のみ」の限定つきで使う |
| 市区町村別の R2 内訳 | 鎌倉市のみあり。他4市町村は行なし | ないものはないと明記する |
| 類型別の R2 内訳（面積・変化量・純変化） | あり（region_landscape の R2 行、4類型） | 森林卓越の singleton 率は変化 0 のため None であり、率として扱わない |

## 5. 結果

### 5.1 類型別の変化量：都市的メッシュが変化の 80.0% を占める

| 類型 | 陸域 | 変化面積 | 変化セル数 | 変化率（基数 = 類型陸域） | 変化全体に占める割合 |
|---|---:|---:|---:|---:|---:|
| 都市的 | 10.61 km²（69.2%、1,010セル） | 0.4622 km² | 44セル | 4.36% | **80.0%** |
| その他混在 | 3.37 km²（22.0%、321セル） | 0.063 km² | 6セル | 1.87% | 10.9% |
| 農地混在 | 1.01 km²（6.6%、96セル） | 0.0525 km² | 5セル | 5.21% | 9.1% |
| 森林卓越 | 0.34 km²（2.2%、32セル） | 0 km² | 0セル | 0% | 0% |
| **合計（地域行）** | **15.32 km²（1,459セル）** | **0.5777 km²** | **55セル** | **3.77%** | **100%** |

率の順位（農地混在 5.21% ＞ 都市的 4.36%）と絶対量の順位（都市的 ≫ その他混在 ＞ 農地混在）は
逆転している。率だけを見れば「農地混在類型で変化が最も活発」に見えるが、絶対量では
都市的メッシュの変化が他の3類型の合計（0.1155 km²、11セル）の約4倍である。
変化の 1セル成分は地域全体で 65.5%（36セル）、都市的メッシュ内でも 61.4%（27セル相当）、
その他混在では 100%（6セルすべて）である。したがって変化量の地理的性格は都市的と断定できるが、
変化量そのものの実変化／判読差の区別は、1週目 H2 の保留を引き継ぐ。

### 5.2 H1 の検証 — 支持

| 支持条件 | 実測値 | 判定 |
|---|---|---|
| (a) 都市的メッシュの変化割合 50%超 | **80.0%**（0.4622 km² / 0.5777 km²） | 満たす |
| (b) 都市的メッシュの変化 ＞ 他3類型の合計 | 0.4622 km² ＞ 0.1155 km²（11セル） | 満たす |
| (c) 建物用地純変化の符号の一致 | 都市的 +0.084 km²（+8セル）、地域全体 +0.0525 km²（+5セル） | 満たす |

3条件すべてを満たしたため、H1 は **支持** される。
地域全体の建物用地純増 +0.0525 km² は、都市的メッシュの +0.084 km² から
農地混在の −0.0315 km²（−3セル）を差し引いた残りであり、その他混在は 0 km² である。
つまり地域行の建物用地の符号は都市的メッシュの動きが決めており、
「R2 の建物用地は純増」という記述は、実質「鎌倉市北部の都市部で建物用地が純増」の言い換えである。
都市的メッシュ内の建物用地の動きは、増加 0.2416 km²（23セル）に対して減少 0.1576 km²（15セル）で、
純増はその差し引きの結果に過ぎない。増加・減少とも 1セル成分を多く含むため、
純増の規模（8セル）を地域トレンドとして読むことはできない。

### 5.3 総流入と純変化の分離、逆方向遷移

| 指標 | 総流入・総減少 | 純変化 | 備考 |
|---|---|---|---|
| 森林への流入（農地→森林＋建物→森林） | 0.0945 km²（9セル） | 森林純変化 −0.042 km²（−4セル） | 森林化率 0.86%（非森林基数 10.99 km²）だが純変化は負 |
| 森林の流出（implied） | 0.1365 km²（13セル） | — | 流入 − 純変化からの implied 値 |
| 都市的メッシュの森林 | 流入 0.0525 km²（5セル） | −0.0525 km²（−5セル） | 流出 implied 0.105 km²（10セル）で、流入の2倍 |
| 農地の総減少 | 0.042 km²（4セル） | −0.000004 km²（約0セル） | 増加 implied 0.042 km²（4セル）で相殺され検出限界以下 |
| 農地混在類型の農地 | 総減少 0.0105 km²（1セル） | +0.021 km²（+2セル） | 増加 implied 0.0315 km²（3セル）が減少を上回る |

森林化率 0.86% は1週目の値と同じだが、森林純変化が −0.042 km² である以上、
「森林化が進んでいる」とは読めない。都市的メッシュでは森林への流入 5セルに対して
流出 implied 10セルがあり、森林の入れ替わり（churn）が純減を伴っている。
農地については、地域全体の純変化が検出限界以下であるにもかかわらず、
類型別に見ると農地混在で純増、都市的・その他混在で純減（各 −0.0105 km²、−1セル）と
符号が割れており、地域行の「ほぼ不変」は相殺の結果である。
類型別の農地→森林は都市的・農地混在・その他混在で各 0.0105 km²（1セルずつ）であり、
類型間で大小を論じる材料にはならない。建物→森林は都市的 0.042 km²（4セル）と
その他混在 0.021 km²（2セル）の合計 0.063 km²（6セル）である。

### 5.4 H2 の検証 — 支持（方法論ルールとして）

| 支持条件 | 実測値 | 判定 |
|---|---|---|
| (a) R2 限定のバッファ集計が存在しない | 250 m・500 m とも site_buffers の index は `p32_sites` の pooled のみ | 満たす |
| (b) pooled バッファの区分軸に地域が含まれない | by_class の index は「天然記念物を含まない／含む」のみ | 満たす |
| (c) 利用可能地点の選定が収録範囲に依存する | 収録範囲の境界から 500 m 以上内側という選定条件（1週目 §6.3） | 満たす |

3条件すべてを満たしたため、H2 は **支持** される。
R2 の利用可能地点は 3地点（108地点中 2.8%）で、網羅率 7.4%・excluded と並べると、
地点数の少なさが収録範囲の狭さの帰結であることが見える。
ただし R5 も利用可能地点は 3地点でありながら網羅率 100%・comparable であるため、
「地点数が少ないから比較できない」のではなく、「地域別バッファ値が存在しないから
比較表に R2 の行を作れない」が正確な理由である。pooled のバッファ値（108地点）に
R2 の 3地点が含まれていること自体は否定しないが、R2 単独のバッファ値を引用することはしない。
なお R2 の 3地点について地点数以外に既存集計で言えることは、以上の構造確認以外にはない。
個別地点の座標・名称は本シリーズの境界（Phase 1-D の実解析をしない）に抵触するため扱わない。

## 6. 考察

1. **「R2 の変化」は二重の限定つきの値である。**
   第1の限定は地理で、収録範囲は三浦半島全体ではなく鎌倉市北部のみである（1週目 H1）。
   第2の限定は本レポートで定量化した類型で、収録範囲内の変化の 80.0% は都市的メッシュの変化であり、
   建物用地純変化の符号も都市的メッシュが決めている。したがって「R2 の変化」を
   半島の農地・森林の動態として読むことは二重に誤りであり、正しい言い換えは
   「鎌倉市北部の都市部の、55セル規模のセル変化」である。
2. **都市部の変化は、都市計画の文脈とは整合するが、因果の証拠にはならない。**
   鎌倉市都市マスタープランが大船・深沢ゾーンを都市的な拠点圏として位置づけていること（§2 の 1）は、
   収録範囲が都市的な動きを拾いやすい構造にあることの裏付けにはなる。
   しかし計画文書は時系列データではなく、2014→2021年の建物用地の増減（増加 23セル・減少 15セル）の
   原因としては使えない。増加と減少が拮抗し、1セル成分が 61.4% を占める都市的メッシュの変化は、
   2021年の判読方法の変更と判読差ノイズを含みうるため、実変化のトレンドとしては保留する（1週目 H2 を継続）。
3. **見えない南部の農地こそ、廃墟調査の観点では盲点のままである。**
   三浦市の第1次産業構成比 11.9%（§2 の 3）と、2026年9〜10月の台風被害報道（§2 の 2）は、
   期間も出所も異なるため 2014→2021年の変化と因果でつながない。
   それでも両者は同じ構造を示す。すなわち、半島の農業の中心と災害曝露の高い農地は
   そろって C2 の収録範囲外にあり、C2 の集計をこね回しても盲点は埋まらない。
   R2 で廃墟調査の探索ロジック（建物用地→森林・荒地遷移を痕跡とみる型）を作動させるには、
   まず C2 とは別の収録範囲を持つ資料が必要である。
4. **P32 の比較可能性ルールは、R2 だけの例外処理ではない。**
   地域別バッファ値が存在しない地域を比較表に入れない、というルールは、
   今後の地域でも「バッファ値の区分軸に地域があるか」を棚卸しで確認することで一般化できる。
   地点数だけを基準にすると、網羅率 100% の R5（3地点）まで誤って除外してしまう。
   基準は「値の存在」と「選定条件の収録依存性」の2点である。
5. **限界の明記。** 対象期間は 2014→2021年で、2021年には判読方法の変更がある。
   変化の 65.5% が1セル成分、72.7% が小成分であり、小さい遷移は判読差ノイズを含みうる。
   セルは重心で市区町村に帰属しており、境界付近のセルは帰属のぶれがありうる。
   網羅率は面積ベースであり、人口・建物数ベースの網羅率ではない。
   2026年の台風被害報道と 2014→2021年の土地利用変化は期間が重ならないため、因果の接続はしていない。
   森林卓越類型（32セル）は変化 0 であり、「森林卓越メッシュは安定している」という記述は
   収録範囲内の 0.34 km² についての記述に過ぎず、半島南部の森林については何も言っていない。

## 7. 反省点（翌日 R3・2週目への引き継ぎ）

1. **excluded 地域の2週目は、類型別の掘り下げで「都市切片」仮説のような限定の定量化ができる。**
   1週目で「言えないこと」を固定しておくと、2週目は同じデータからでも類型別の変化量という
   新しい切り口が作れた。R3・2週目でも、1週目の結論（沿岸部の欠け・内陸偏重）をなぞるのではなく、
   類型別の変化量で「内陸偏重の変化はどの類型の変化か」を定量化すること。
2. **implied 値（森林流出量・農地増加量）は、算出式を明記しないと一次集計の値と誤読される。**
   今日は §4 と §5.3 で算出式を明記したが、スクリプトの docstring にも同じ式を残した。
   R3・2週目でも implied 値を使う場合は、表の注記とスクリプトの両方に式を書くこと。
3. **類型別の1セル遷移は、合計としては使えても類型間比較には使えない。**
   今日の農地→森林は各類型 1セルずつで、類型別の大小を論じれば誤読になる。
   R3・2週目でも、類型別の遷移が 1〜2セルに割れる場合は合計値に集約し、類型別の順位付けはしないこと。
4. **前日レポートが不在の場合の代用手順を明文化する。**
   今日は R1・2週目の不在を冒頭で明記し、直近の R7・1週目で代用した。
   代用した場合は「代用であること」と「本来の前日分が欠落していること」の両方を報告に残し、
   代用元の反省をそのまま前日の反省として報告しないこと。
5. **P32 の比較可能性は、地点数ではなく「値の存在×選定条件」で判定する。**
   今日の H2 の判定枠は他地域にも転用できる。R3・2週目では、R3 の利用可能地点数と
   バッファ値の区分軸を同じ枠で確認し、比較表に入れる／入れないの根拠を明記すること。

## 8. 来週の R2（3週目）への宿題

- 都市的メッシュ内の建物用地の増減（増加 23セル・減少 15セル）が実変化か判読差かを、
  既存集計の範囲でさらに切り分ける手がかりがないかを確認する。次期データが来るまでは
  保留が続く見込みだが、増加セルと減少セルの類型内分布（都市的メッシュ内での偏り）が
  既存集計で言えるかどうかを棚卸しする。
- 森林卓越類型（32セル、変化 0）の「安定」が R2 固有か他地域と共通かを、他地域の
  森林卓越類型の変化率と並べて確認する。ただし R2 は excluded のため、比較は参考値として扱い、
  順位付けには使わない。
- 前日レポート不在の件（2026-11-02、R1・2週目）がシリーズの欠落として残るため、
  3週目の R2 では本レポートの H1・H2 の継続確認に加え、欠落回の有無を冒頭で再確認する。
