## 1. 数え方

非公開の candidates.csv を、日付ディレクトリと当日の出力から読んだ。座標と候補名は公開 JSON に出していない。

状態が空で、outcome が「維持」の行は再検証にした。2026-11-08 以前で状態の列が無い行は既存にした。これは週3のレビューと同じである。

分類は状態を先に見る。負例、状態変化、棄却、保留は、その状態の分類にする。それ以外は種別を、廃社、廃寺・廃堂、消失集落、廃道、廃駅・廃線、廃施設へ寄せる。神社の行が再検証や新規でも、分類名は廃社になる。これは廃止が確定したという意味ではない。確度の列を別に見る。

2026-11-19 と 2026-11-20 は未実施である。ファイルが無いことを 0 件とは書かない。その日の CSV が現れたら、スクリプトは埋める前に止まる。

## 11. 根拠の質の総評

高が 0 なのは、旧版地形図の記号を見ていないからである。公開タイルの 1936–1942年は東京と大阪に限られ、県西の既存座標では 1945–1950年も 404 だった。遺構の強は累計で 0、未確認が 163 である。存在と廃止が強でも、遺構が未確認なら総合は中までにしている。

廃社の採用が 0 のままなのは、目録の存在リスト、合祀の記録、神社庁の由緒、投稿を、廃社にしなかったからである。分類名が廃社の 18 は、R2 の低のままである。

負例と状態変化が増えたのは、遷座先、合祀先、復祀、現社、現行トンネル、通行止め、付け替えを、廃止と分けたからである。行が増えたことは、消えたものの増加ではない。

## 12. 未解決と、見直しの選択肢

実行はしない。優先の高いものから書く。

1. 旧版地形図を、焦点セルと座標のある候補の周囲だけ、閲覧サービスの謄本で見る。公開タイルの欠測を、記号を見たことにしない。これが無い限り、高は付けない。
2. 神社明細帳の画像を、県のデジタル公開がある郡から読む。公開目録が 0 件だった郡は、0 件のまま廃社にしない。概要の合併語だけでは格上げしない。
3. ダムと水没は、地区名のある町史か工事誌を開いてから分ける。戸数の総数を地区の数にしない。
4. 熱海軌道は、駅ごとの台帳が取れてから ID を付ける。例示の駅名と、現在の鉄道駅を混ぜない。
5. 外部の投稿は、同じ日に一次資料を開いたものだけ採番する。開けなければ保留のままにし、低の行を増やさない。
6. 地域は 7 日で一周させず、一次資料が取れた地域だけを次の回にする。未実施の R4 week4 と R5 week4 は、埋め戻しではなく、再開時に最新の申し送りから始める。
7. 頻度は、日次を再開する前に、上記 1 から 3 のどれかが取れてからにする。取れない間は、日次の採番を続けない。

1. 入力は、2026-11-05 の特別回から 2026-11-21 までの非公開 candidates.csv と、2026-11-22 の candidates.csv である。公開側の各日のレポートと JSON は、件数の照合に使う。2026-11-19 と 2026-11-20 のファイルは無い。
