## 1. 現在分析できていること（R2）

### 1.1 まず結論：R2 について「三浦半島の値」として語れる集計は存在しない

- **網羅率 7.4%**（収録面積 15.32 km² / 地域面積 206.80 km²）、scope は `excluded`。
  未収録は **191.48 km²（92.6%）**で、推定も外挿もしていない（地域別分析 §1 の方針通り）。
- 公開済み地域別分析 §2 の地域別表には **R2 の列そのものがない**。
  これは欠落ではなく、excluded の地域を比較から除外するという同レポートの明示的な方針によるものである。
- したがって本レポートで「R2 の値」として示す数値は、すべて **「鎌倉市北部のみの収録範囲内」**
  という限定つきの値であり、三浦半島全体の値ではない。地域名を冠して読むこと自体が誤りになる。

### 1.2 収録範囲の偏り：1,459セルすべてが鎌倉市

- municipality 集計で R2 に属する行は **鎌倉市のみ**（陸域 15.32 km²、1,459セル、網羅率 38.6%・`reference_partial`）。
  市区町村行の合計（15.32 km²、1,459セル）は地域行と一致する。つまり地域行 = 鎌倉市行である。
- 横須賀市・逗子市・三浦市・葉山町は coverage の `not_covered` リストにあり、**収録率 0%**。
  municipality 集計行そのものが存在しない。
- 鎌倉市自体も 38.6% しか収録されておらず、収録面積から逆算した鎌倉市域は約 39.67 km²。
  地域別分析 §1 は収録範囲を「鎌倉市北部のみ」と記す。町丁レベルの収録範囲は既存集計にはないため、
  本レポートでは「鎌倉市北部」としか特定しない。
- **C1（基盤地図情報の建物・道路縁 2014→2025）**については、県域45メッシュのうち実解析は
  pilot 2メッシュのみで（前日レポート §1 による）、R2 を対象とした建物・道路の版間分析は成立していない。
  本レポートの建物に関する言明はすべて C2 の「建物用地セル」の話であり、棟数・存廃の話ではない。

## 3. 仮説

### H1（主仮説）: R2 の集計値は三浦半島全体の値として使えない

検証前に置いた支持条件（すべて満たせば支持）:

- 地域網羅率が **30%未満**（scope 規則の excluded 閾値）であること
- 収録セルが **1市区町村のみ**に属すること
- 構成市区町村のうち少なくとも1つが **収録率 0%** であること

背景: もしこれらが満たされれば、「R2 の農地減少率」「R2 の森林化率」といった地域値の公表は、
半島の実態ではなく鎌倉市北部という切片の値の誤表示になる。本プロジェクトが R2 を語るには、
まずこの誤表示を封じることが先決である。

### H2（副仮説・限定観察）: 収録範囲内（鎌倉市北部）の2014→2021年変化は、
### セル数ベースで見ると判読ノイズ水準に留まり、地域トレンドとして読めない

検証前に置いた判定条件（すべて満たせば「トレンドとして読める」とし、1つでも欠ければ **保留**）:

- 分類が変化した陸域が **1 km²以上**あること
- 変化のうち1セル成分の割合が **50%未満**であること
- 主要な遷移（農地総減少・建物用地の増減など）が **10セル超**の規模であること

背景: 前日の R1 では変化面積が 32.89 km²、1セル成分 58.7% であった。
R2 の収録範囲はその約 1/37 の面積しかないため、同じ読み方をそのまま持ち込むと
数セルの動きが大きな率に見えてしまう。H2 はその罠を回避するための判定枠である。

## 4. 分析方法と棚卸し

- `phase1c2_results.json` の coverage / region / municipality / region_landscape 集計を再計算。
  1セル = 陸域 15.32 km² / 1,459セル = **0.0105 km²**。面積をセル数に換算して示す。
- 変化の1セル成分は、region 集計の `singleton_change_share` と
  transitions の `component_class_share_by_region` の R2 行で確認した（両者は一致する）。

### 棚卸し：使う数値が機械可読な一次集計にあるか

| 使いたい数値 | results.json にあるか | 扱い |
|---|---|---|
| R2 の網羅率・収録面積・scope | あり（coverage） | そのまま使う |
| R2 の地域集計（構成・純変化・遷移） | あり（aggregates.region の R2 行） | ただし「鎌倉市北部のみ」の限定つきで使う |
| 市区町村別の R2 内訳 | 鎌倉市のみあり。他4市町村は行なし | ないものはないと明記する |
| 農地→建物用地（R2） | なし。公開表にも R2 列なし | 使わない。残差 1セル分は「行き先不明の合計」としてのみ示す |
| 農地→森林・荒地、建物→森林・荒地 | あり | セル数と併記して使う |
| 類型別の R2 内訳 | あり（region_landscape の R2 行） | 基数 0.5 km² 未満の率（other_mixed の農地など）は順位付けに使わない |
| P32 文化財の R2 地点数 | あり（地点数のみ、R2 = 3） | 地点数のみ使う。R2 限定のバッファ集計はないので周辺土地利用は語らない |
| C1 の R2 建物・道路分析 | なし（pilot 2メッシュのみ） | 扱わない |

小ささのアーティファクトである。これを「三浦半島では農地の森林化が進んでいる」と読めば、
まさに前日の反省 1 が警告した誤読になる。
同様に、other_mixed 類型の農地→森林率 33.3% は、基数 0.03 km²（3セル）中の 1セルであり、
順位付け・比較から外した。

## 6. 考察

1. **R2 の「値がないこと」自体が、本プロジェクトへの最大の含意である。**
   廃墟調査の探索ロジック（建物用地→森林・荒地遷移を痕跡とみる型）は、遷移が測れていない地域では
   そもそも作動しない。R2 では、人口減少が県内最大規模で進む横須賀市（2020→2025年、§2 の 5）と、
   第1次産業の中心である三浦市（§2 の 3）が、そろって収録率 0% である。
   つまり「廃墟化のシグナルが最も出やすいと想定される場所」と「データの盲点」が重なっている。
   R2 で探索を進めるには、まず C2 とは別の収録範囲を持つ資料が必要であり、
   C2 の集計をこね回しても盲点は埋まらない。
2. **収録範囲内の値は「鎌倉市北部の都市的切片」としてのみ意味がある。**
   建物用地比率 55.7%、類型別の都市的メッシュ 69.2% は、半島の姿ではなく、
   収録された鎌倉市北部の姿である。半島南部（横須賀・三浦）の海岸・台地・農地の景観は
   この数値に一切含まれていない。R2 の地域行を他地域と並べて比較表に載せることは、
   比較の前提を壊すため行わない（公開レポート §2 が R2 列を省いた判断は正しい）。
3. **P32 文化財の地点数（R2 = 3、利用可能 108地点中）も同じバイアスを抱える。**
   P32 の利用可能地点は「収録範囲の境界から 500 m 以上内側」という条件で選ばれており、
   収録範囲が狭い R2 では地点が入りにくい構造になっている。R2 の 3地点が少ないことは、
   半島の文化財が少ないことの証拠にはならない。R2 限定のバッファ集計は既存集計にないため、
   文化財周辺の土地利用について R2 単独の言明はしない。
4. **限界の明記。** 対象期間は 2014→2021年で、2021年には判読方法の変更がある。
   変化の 65.5% が1セル成分であり、小さい遷移は判読差ノイズを含みうる。
   セルは重心で市区町村に帰属しており、境界付近のセルは帰属のぶれがありうる。
   網羅率は面積ベースであり、人口・建物数ベースの網羅率ではない。
   2020→2025年の人口動態と 2014→2021年の土地利用変化は期間が重ならないため、
   因果の接続はしていない。次期データが来たときに初めて、人口減少局面の横須賀市で
   建物用地の動きがどう出るかを検証できる論点として記録する。

## 7. 反省点（翌日 R3 への引き継ぎ）

1. **excluded 地域のレポートは、数値の羅列より「言えないことの棚卸し」が本体になる。**
   今日は棚卸し表を §4 に置いてから仮説を組んだことで、ない数値に仮説が依存する事故を防げた。
   明日の R3（湘南、網羅率 83.4%・reference_partial）では逆に「言える範囲」が広がるため、
   棚卸しの焦点を「沿岸部の欠けがどこに効くか」に切り替えること。
2. **「地域行 = 1市区町村行」という同一性の確認は、集計の最初にやるべきだった。**
   今日は municipality 行の合計と地域行の一致をスクリプトの検証項目に入れて確認できたが、
   地域行の値を読む前にこの同一性を疑う習慣を標準化する。R3 では8市町の内訳を確認してから地域値を読むこと。
3. **率の罠の実例は、率と絶対量・セル数を同じ表に並べると説得力が増す。**
   今日の §5 の表はその形になった。R3 でも同じ表形式を使い、基数 0.5 km² 未満の率は
   表に載せても順位・比較から外す注記を付けること。
4. **外部資料の「期間」と「収録範囲」の二重のずれに注意する。**
   今日は期間のずれ（2020→2025年 vs 2014→2021年）に注意したが、外部資料の対象範囲
   （例: 三浦市のみの記述を半島全体の記述と読み違える）にも同じ注意が要る。
   R3 でも、湘南の市町別の記述を地域全体の記述と混同しないこと。
5. **P32 の地点数は、収録バイアスの指標としても使える。**
   今日は R2 = 3地点を「少ない」として片付けかけたが、利用可能地点の選定条件そのものが
   収録範囲に依存することに気づけた。R3 では地点数と網羅率の関係を意識して読むこと。

## 8. 来週の R2（2週目）への宿題

- 収録範囲の地理的偏りを、1 kmメッシュの類型別内訳（都市的 69.2%）からさらに掘る。
  今回は類型別の面積までしか見ていないため、次週は類型別の変化量（都市的メッシュの変化 0.46 km²など）と
  収録範囲の都市偏りの関係を整理し、「収録範囲内の変化は都市部の変化である」という限定を定量化する。
- R2 の P32 3地点について、既存集計で言えることが地点数以外にないかを再確認する。
  今回はバッファ集計がないことを棚卸しで確認したが、次週は他地域の P32 バッファ集計との
  比較可能性（比較対象として R2 を入れるべきでない理由）を明文化する。
