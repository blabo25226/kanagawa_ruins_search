## 2. 周知の事実・地域の特徴（ウェブ検索による裏付け）

すべて対象期間を併記する。期間の異なる事実同士を因果でつながない。
また「相模原市」「緑区」の一般名と、本プロジェクトの R6 定義
（CODH 2005-01-01 時点の旧津久井郡 4 町域）は別物であることに注意する。

1. **旧津久井郡は、1955年の合併の結果、城山町・津久井町・相模湖町・藤野町の4町で構成されることとなった。
   面積は 238.44 km²、2町編入直前の 2006年3月1日当時の郡域の総人口は 72,871人であった。**
   （出典: Wikipedia「津久井郡」、
   http://ja.wikipedia.org/wiki/津久井郡 ）
   津久井町・相模湖町が 2006年3月20日に、城山町・藤野町が 2007年3月11日に相模市へ編入され、
   津久井郡は消滅した。2010年4月1日の政令指定都市移行と同時に、旧郡域は緑区の一部となった。
   対象期間は 1955〜2010年の行政史であり、2014→2021年の土地利用変化の原因としては使わない。
   ここでの要点は、R6 の陸域 238.38 km² が旧郡域の面積 238.44 km² と 0.06 km² の範囲で一致し、
   R6 が「市の一部」ではなく「旧郡域そのもの」を切り出した地域だということである。
2. **旧郡域は、丹沢山地の北側に位置し、相模原台地の北西端を占める城山町東部を除き、全域を山地が占める。
   その間を相模川や道志川、串川およびそれらの支流が流れ、それらの河川によって形成された
   断片的な河岸段丘がわずかな平坦地として分布する。**
   （出典: Wikipedia「津久井郡」、同上）
   道志川を境に北西側の上津久井（旧藤野町・相模湖町）と南東側の下津久井（旧津久井町・城山町）に分けられる。

## 3. 仮説

### H1（主仮説）: R6 の値は相模原市全体の値でも緑区の値でもなく、旧津久井郡 4 町域という森林・山地地域の値である

検証前に置いた支持条件（すべて満たせば支持）:

- R5＋R6 の陸域（セル数）が区行合計と一致し、R6 単独の陸域が区行合計と一致しないこと
- R5 と R6 の建物用地率（2014年）の差が **50ポイント超**であること
- R5 と R6 の森林率（2014年）の差が **50ポイント超**であること
- 森林卓越メッシュの陸域が R6 陸域の **70% 超**であること

背景: R5 では区行合計 ≠ 地域行であり、問題は集計単位の取り違えだった。
R6 ではさらに、R6 自体が市区町村行を持たない旧郡域の切り出しであり、
区行・市行のどちらを代理にしても誤読になる。H1 は、その誤読の危険を数値で検証する。

### H2（副仮説）: R6 の 2014→2021年変化は、都市的転換型ではなく森林縁辺型である

検証前に置いた支持条件（すべて満たせば支持。森林縁辺型の定義）:

- 森林化率（非森林陸域→森林）が **3% 超**であること
- 建物用地→森林・荒地率が **1.5% 超**であること
- 農地総減少に占める農地→森林・荒地の割合が **20% 超**であること

対立仮説として、R1・R3・R4 と同じ都市的転換型の 3 条件も別に照合する
（農地→森林・荒地が農地総減少の 10% 未満、建物用地の純変化がプラス、
農地→森林率が 2% 未満）。都市的転換型の条件を満たさないことと、
森林縁辺型の条件を満たすことは別の判定であり、どちらか一方だけでは結論しない。
また「森林化率」は総流入の率であり、森林面積の純変化とは別であることを明記する。
森林面積が純増していなくても、森林縁辺型の判定は変わらない。

背景: R5 では農地→森林・荒地は農地総減少の 2.3% に過ぎず、建物用地は純減だった。
R6 は森林率 80.2% で、森林への転入が相対的に大きいと予想される。
ただし変化した陸域の割合自体は小さいため、率の高さが絶対量の大きさを意味しないことにも注意する。

### H3（副仮説・廃墟調査への含意）: R6 では、建物用地→森林・荒地および
### 農地→森林の遷移は、まとまったパッチとして存在しない

検証前に置いた支持条件（すべて満たせば支持）:

- 建物用地→森林と農地→森林の両方で、最大の成分が **5セル未満**であること
- 両方の遷移で、5セル以上の成分の割合が **0%** であること

背景: 本プロジェクトの廃墟探索ロジックは、建物用地→森林・荒地遷移を痕跡とみる型である。
遷移がすべて 1〜3セルの孤立成分であれば、判読ノイズと実変化を区別できず、
探索の手がかりとしては使えない。H3 はその可否を判定する。
なお focus_by_region の成分構造は地域全体のものであり、類型別・旧町別の
成分構造は results.json にないため、類型別の率からパッチの有無は推論しない。

## 4. 分析方法と棚卸し

- `phase1c2_results.json` の coverage / region / municipality / region_landscape /
  transitions（focus_by_region）集計を再計算。1セル = 0.0105 km²。
- 地域行と区行合計の不一致、R5＋R6 = 区行合計、類型別内訳の合計をスクリプトのアサーションで検証した。

### 棚卸し：使う数値が機械可読な一次集計にあるか

| 使いたい数値 | results.json にあるか | 扱い |
|---|---|---|
| R6 の網羅率・scope | region 集計にあり（100%・comparable）。coverage.by_region の R6 行はなし、R5 行は市全体相当（328.87 km²） | coverage 表の R5 行は R6 の値として使わない。網羅率は公開レポート §1 の地域表と region 集計に基づく |
| R6 の地域集計（構成・純変化・遷移） | あり（aggregates.region の R6 行） | 地域全体の値として使う（ただし H1 の通り旧郡域の値という注記つき） |
| R6 の市区町村行・旧町別行 | なし（R6 は市区町村ではない）。相模原 3 区行はあるが緑区行は R5 を含む | R6 の内訳として使わない。参考としてのみ掲げ、緑区行は R6 の値として読まない |
| 農地→建物用地（R6） | なし（region 集計に列がない） | 公開レポート §2 の面積表（津久井 0.70 km²）からの補助引用に留め、仮説の判定には使わない |
| R6 の類型別内訳 | あり（region_landscape の R6 行 4 類型、すべて陸域 0.5 km² 超） | そのまま使う。ただし森林卓越内の建物用地基数 2.34 km² は小さいため率と絶対量を併記する |
| P32 の地域別内訳 | 地点数（R6 = 6）のみ | R6 限定のバッファ集計はないため、地点数と網羅率を並べて読むに留める |
| 距離帯・Moran・OSM の R6 限定値 | なし（県域全体または津久井窓のもの） | R6 の言明には使わない |

## 6. 考察

1. **R6 の「100%」は、R5 の「100%」とは違う種類の問題を出す。**
   R5 は「区行合計 = 地域行」が成立せず、問題は集計単位の取り違えだった。
   R6 はそもそも市区町村行を持たず、区行合計は R5＋R6 であって R6 ではない。
   comparable というラベルは、集計単位の対応までは保証しない。
   coverage 表に R6 行がないことも含め、R6 では「何の 100% か」を
   最初に固定しないと、すべての後続の数値が誤読される。
2. **R6 の変化は、面積の割合では小さく、率では大きい。**
   分類が変化した陸域の割合は 2.23% で、R1（5.73%）・R3（6.58%）・R4（4.32%）・R5（6.03%）より小さい。
   しかし森林化率 3.86%・建物用地→森林・荒地率 1.78% は、比較可能な地域の中で突出して高い。
   これは、非森林陸域（47.23 km²）や建物用地（16.52 km²）という基数が小さいため、
   絶対量 0.29 km² の遷移でも率が大きく見える構造である。
   率の高さを「森林化が大規模に進んでいる」と読むことはできない。
   森林面積自体は −0.09 km² でほぼ横ばいであり、森林への総流入と総流出がほぼ相殺している。
3. **R6 の農地減少は、森林縁辺型の定義を満たすが、純粋な森林化ではない。**
   農地→森林は農地総減少の 25.9% を占める一方、補助値では農地→建物用地が 0.70 km² と
   農地総減少の 61.9% に当たる。農地の行き先は森林だけではなく、建物用地も主である。
   ただし補助値は判定外であり、判定に使える範囲で言えるのは、
   「農地→森林の率が都市的地域の数倍であり、都市的転換型の定義には当てはまらない」ことである。
   2週目では、公開レポートの面積表・類型別表で農地の行き先の内訳が
   補えるかを確認することが宿題になる。新たな推定や外挿は行わない。
4. **廃墟調査への含意は、R3・R4・R5 と同じく「手がかりなし」であるが、理由が違う。**
   R3 では沿岸部の欠けが、R4 では孤立成分のみであることが理由だった。
   R5 では収録範囲に欠けはなく、遷移自体が極めて小さく、すべて 1セル成分であることが理由だった。
   R6 では遷移の率こそ高いが、絶対量は建物用地→森林 0.29 km²・農地→森林 0.29 km² と小さく、
   すべて 1〜3セル成分で、ほぼすべて境界上である。
   したがって C2 の集計から R6 の廃墟候補を絞り込むことはできない。
   なお R6 の建物用地→森林の逆方向（森林→建物用地 0.44 km²）が順方向より大きいことは、
   建物用地の純増が森林からの転入だけでは説明できないことを示すが、
   その内訳は results.json の region 集計にはない。
5. **限界の明記。** 対象期間は 2014→2021年で、2021年には判読方法の変更がある。
   変化の 59.2% が1セル成分であり、小さい遷移は判読差ノイズを含みうる。
   セルは重心で市区町村・旧郡域に帰属しており、緑区内の R5／R6 境界付近のセルは
   CODH 2005-01-01 時点の旧行政界による帰属であり、現行の区界とは異なる。
   網羅率は面積ベースであり、人口・建物数ベースの網羅率ではない。
   行政史（1955〜2010年）・現況説明・2020年の資料と 2014→2021年の土地利用変化は期間が重ならないため、
   因果の接続はしていない。P32 の地点数（R6 = 6）は、収録範囲の境界から 500 m 以上
   内側という選定条件の下での数であり、文化財の密度の証拠にはならない。

## 7. 反省点（翌日 R7 への引き継ぎ）

1. **市区町村行を持たない地域では、区行合計＝地域行の検証の代わりに「地域行＋隣接地域行＝区行合計」の検証を最初に行う。**
   R6 では R5＋R6 = 区行合計で一致し、緑区行を R6 の内訳として使う誤りを防げた。
   R7（県西）は市区町村行を持つため、R4 の群合計手順に戻るが、reference_partial（46.7%）であるため、
   群合計の前に市町村網羅率表を §1 冒頭に置き、欠けの地理を先に固定すること。
2. **coverage 表に地域行がない場合は、その不在自体をスクリプトのアサーションで確認する。**
   R6 では coverage.by_region に R6 行がないことが、R5 行の市全体相当とセットで罠になっていた。
   R7 でも coverage 表の行と公開レポート §1 の地域表の対応を最初に確認すること。
3. **「総流入の率」と「純変化」を判定表で分ける。**
   R6 では森林化率 3.86% と森林純変化 −0.09 km² が併存した。率だけを見て「森林が増えている」と読む誤りを防ぐため、
   総流入・純変化・算術的な総流出を同じ表に並べること。R7 でも森林化率が高いため、同じ表を使うこと。
4. **率の順位と絶対量の順位が一致しない場合は、両方の順位を併記する。**
   R6 では森林化率の順位（森林卓越が最大）と森林への遷移の絶対量の順位（その他混在が最大）が一致しなかった。
   率の順位だけを本文の議論に使わないこと。
5. **P32 の地点数は、網羅率と並べて読む。**
   R6 は網羅率 100% で 6 地点である。R7 は網羅率 46.7%・reference_partial で 10 地点であり、
   地点数の多寡を文化財の多寡と読み替えない注意は、R7 でも繰り返すこと。
   特に R7 では収録範囲が山北町・松田町に偏るため、地点の地理的偏りにも注意すること。

## 8. 来週の R6（2週目）への宿題

- R5 との対比を正式に行う。本レポート §5.1 で対比の骨格は整理したが、
  2週目では農地の行き先の内訳（農地→建物用地の補助値 0.70 km² と農地→森林 0.29 km² の関係）と
  建物用地の総増加 1.25 km² の内訳が、公開レポートの面積表・類型別表で補えるかを確認する。
  新たな推定や外挿は行わない。
- 森林への総流入 1.82 km² と森林からの総流出約 1.92 km² の内訳について、
  類型別表で森林卓越・その他混在・農地混在のどれが流出の主因かを確認する。
  流出先の完全な内訳は results.json にはないため、断定しない範囲を維持する。
- 旧町別（城山・津久井・相模湖・藤野）の内訳は region_landscape では分離できないため、
  R6 の類型表は地域全体のものとして扱い、旧町別の類型推論をしない範囲を維持する。
