- 「その他」は L03-b のコード 1000 である。ゴルフ場（1600）は別群で、その他に含めていない。コード 1000 の中身（空地、公共施設、造成地など）は、この遷移行列では分かれない。
- 公開レポート §2 の面積表に、その他の遷移列は無い。JSON の region 列と region_landscape 列にも `other_from` / `to_other` は 0 個である。

## 2. 周知の事実

- 2014 年と 2021 年の土地利用細分メッシュは、同じ LandUseCd-09 のラベルを使う。コード 1000 は「その他の用地」、1600 は「ゴルフ場」である（国土数値情報 コードリスト、https://nlftp.mlit.go.jp/ksj/gml/codelist/LandUseCd-09.html 、リポジトリの `landuse_codes.toml` は 2026-10-10 に照合）。このラベルは 2014→2021 年の変化の原因ではない。
- 2021 年の判読方法の変更は、週1からシリーズの限界として残っている。今週の小さい純増（都筑区の 10 セル）も、その限界の中で読む。

## 3. 仮説

閾値はセルを集計する前に置いた。すべて満たせば支持する。

### H1（週2 §8）: 「その他」純増は、公開表では閉じず、同じ v0.2.0 のセル遷移では閉じる。純増は建物用地→その他ではない

- JSON と region_landscape に、その他の出所を名指しする列が 0 個である
- 公開レポート §2 の面積表に、その他への遷移の行が無い
- セルのその他の純変化が、地域行の `other_net_change_km2` と 0.015 km² 以内で一致する
- その純変化と、建物用地→その他の総流入との差が 0.05 km² 以上である（前日の手続き。近いからといって等置しない）

### H2（週2 §8、前日の手続き）: 森林→建物用地と森林純減は、差が 0.05 km² 未満でも別の数である

- セルの森林純変化が地域行と 0.015 km² 以内で一致する
- 森林→建物用地が、focus 遷移の逆方向面積と 0.015 km² 以内で一致する
- 森林純減の絶対値と森林→建物用地の差が 0.05 km² 未満である（2 桁では同じに見える）
- 森林の総流出のうち、建物用地以外が 1.0 km² 以上ある

### H3（週2 §8）: 都筑区の森林純増は、単一の 1 km 類型が 50% 超を占める

50% はレビュー追補の閾値で、動かさない。

- セルの類型別純変化の合計が、都筑区の行と 0.015 km² 以内で一致する
- 正の純変化が最大の類型のシェアが、区の森林純変化の 50% を超える

### H4（週2 §8）: 川崎区の建物用地総減少は、その他へ 50% 超、森林と荒地へ 15% 未満である

15% は週1の都市的転換型で使った「森林＋荒地は 15% 未満」である。分母は総減少そのもので、1.49 km² は 0.5 km² を超える。

- セルの総減少が、川崎区の行と 0.015 km² 以内で一致する
- 区の行の建物用地→森林と建物用地→荒地が、どちらも 0 である
- 行き先のその他シェアが 50% を超える
- 森林と荒地のシェアが 15% 未満である
- この結果は、候補地点の絞り込みに使わない

### H5（前日の手続き、レビュー §7 の 8）: 週2の「5 セル以上 9.6%（3.17 km²）」は `share_>=5` であり、1〜2 セルの補集合ではない

- `|share_>=5 − 0.096| < 0.01`
- `|share_>=5 × 変化面積 − 3.17 km²| < 0.05 km²`
- 1〜2 セルの補集合と `share_>=5` の差が 10 ポイント以上である
- 建物用地→森林と農地→森林の 5 セル以上シェアは 0 のままである

## 6. 考察

1. 週2が残した「その他 +5.19 km²」と「森林 −4.37 km² の行き先」は、公開の面積表では閉じない。同じセルでは、用途の名前付きで閉じる。その他の純増は建物用地からの総流入 6.555 km² ではなく、流入 10.268 km² と流出 5.075 km² の差である。森林の純減は森林→建物用地 4.362 km² ではなく、総流出 6.847 km² と総流入 2.474 km² の差である。0.011 km² の近さは、同じ数であることの証拠にしない。
2. 都筑区の森林純増は、都市的メッシュが 70.0%（+7 セル）、農地混在が 30.0%（+3 セル）である。単一類型への帰属は、この 10 セルの内訳として支持する。森林が増えた区域、という読みにはしない。
3. 川崎区の建物用地総減少 1.488 km² の 81.7% はその他、16.2% は交通用地、森林と荒地は 0 である。週1の「建物用地の減少は再開発の循環」と向きが合う。廃墟候補の位置は、この区合計からは出ない。
4. 週2の 9.6% は 5 セル以上の真値である。1〜2 セルの補集合は 21.1% で、別の数として残す。焦点遷移に 5 セル以上は無い。
5. 消失候補は特別回の 24 件を中のまま維持し、神社は 0 のままである。現行の礼拝施設 1,304 件は、消えた社のリストではない。注記の 0 と、旧版の鳥居記号の不在は別である。

## 7. 反省

1. 0.011 km² 差の森林→建物用地と森林純減を、式の前に同じ数だと決めなかった。総流出 6.847 km² を先に出してから、4.362 km² をその一部として書いた。次週も、2 桁で同じに見える対は、総量と一つの遷移を並べてから判定する。
2. 注記の 404 は 7 枚、焦点セル 15、候補は R1-017 の 1 件である。この 15 セルと R1-017 を、注記 0 件に含めない。
3. 語幹の完全一致では、24 件とも現行 OSM・P32・取得できた注記に残らなかった。部分一致に広げると、現存の別施設を巻き込む。次週も完全一致のままにする。
4. 谷（2017）の PDF はテキストが取れなかった。取れていない論文を、読んだ文献に数えない。

## 8. 来週（7日後、2026-11-16）の R1（4週目）への申し送り

経過日数 21 なら `floor(21 / 7) + 1 = 4`、`21 mod 7 = 0` で再び R1 である。着手時に README の式で計算し直す。

1. **その他。** 純増は +5.193 km² である。総流入 10.268 km²（最大は建物用地 6.555 km²）から総流出 5.075 km²（最大は建物用地 3.932 km²）を引いた差である。6.555 km² を純増と呼ばない。コード 1000 の中身は、この遷移では分かれない。ゴルフ場は別群のままにする。
2. **森林。** 純変化は −4.373 km²、総流出は 6.847 km²、森林→建物用地は 4.362 km²、建物用地以外は 2.485 km²（その他 1.133、農地 0.881、交通用地 0.294、ゴルフ場 0.136、荒地 0.042）である。差 0.011 km² を一致の証拠にしない。
3. **都筑区。** 森林純増 +0.105 km² のうち都市的が 70.0%（+7 セル）、農地混在が 30.0%（+3 セル）である。50% は動かさない。10 セルを、森林が増えた区域とは書かない。他類型のセルは 0 である。
4. **川崎区。** 建物用地総減少 1.488 km² の 81.7% はその他、16.2% は交通用地、森林と荒地は 0 である。候補の絞り込みに使わない。

6. **候補。** 採用は 24 件すべて中で、格上げ 0、棄却 0、神社 0 である。次に確かめるのは、この 24 ID の旧版地形図と、建物用地→森林 103 セル・農地→森林 47 セルのうち注記が 404 だった 15 セル、それに R1-017（横浜市戸塚区）の注記である。旧版は正規の交付でその範囲だけを見る。今昔マップと迅速測図のタイルは保存しない。神社の採用は 0 のまま、OSM の欠落で増やさない。現行の礼拝施設 1,304 件は対照の母数であって、候補ではない。終了日付きの社寺型 2 件は鎌倉市で、R1 に入れない。
