## 1. 昭和期空中写真インベントリ（旧津久井4地区）

国土地理院「地図・空中写真閲覧サービス」（2026年3月リニューアル版システム）の検索成果に基づき、旧津久井地域4地区（青野原・青山・鳥屋・寸沢嵐）を撮影範囲に含む昭和期の代表的な空中写真（単写真）を整理した。

### 1.1 時代別撮影計画の概要

1. **1940年代（米軍撮影・終戦直後）**:
   - 撮影時期: 1946年〜1948年（昭和21〜23年）
   - コース代表例: `USA-M46-A-5VV` 等
   - 特徴: モノクロ、高高度（約6,000m）、縮尺約1/40,000。相模ダム完成（1947年）直前の相模川渓谷や旧津久井郡各村の戦後開拓期・農地開墾期の原風景が捉えられている。
2. **1950年代（米軍補足撮影および国土地理院初期）**:
   - 撮影時期: 1953年、1957年、1959年（昭和28〜34年）
   - コース代表例: `USA` シリーズ、`KT592YZ`（コースA20A）
   - 特徴: モノクロ、縮尺1/20,000〜1/40,000。津久井湖（城山ダム）着工前の道志川・串川・相模川合流点周辺の集落構造が記録されている。
3. **1960年代（国土基本図撮影・国土地理院）**:
   - 撮影時期: 1968年、1969年（昭和43〜44年）
   - コース代表例: `MKT684X`（コースC10, C11）、`KT699Y`（コースC12）
   - 特徴: モノクロ、中高度（約3,500m）、縮尺1/20,000。城山ダム・津久井湖（1965年竣工）完成直後の水没地域境界や新道付け替え状況が明確に識別可能。
4. **1970年代（カラー空中写真・国土地理院）**:
   - 撮影時期: 1974年12月（昭和49年）、1978年8月（昭和53年）
   - コース代表例: `CKT7417`（コースC28, C29）、`KT783Y`（コースC8）
   - 機材: RC10 航空カメラ、カラーリバーサルフィルム、縮尺1/15,000、撮影高度3,300m。
   - 特徴: 植生・地形・建物屋根の色彩弁別が可能。宮ヶ瀬ダム着工前の中津川上流・早戸川合流部（青野原・鳥屋南部）の集落・森林境界の基準となる。

## 3. 歴史絵図・村絵図インベントリ

旧津久井地域に伝存する近世絵図・字絵図の現存状況および公開・閲覧条件を調査した。

### 3.1 『相州津久井領絵図（平本家本）』

- **指定**: 相模原市指定文化財（有形文化財・歴史資料、平成19年4月1日指定 / 旧津久井町指定を引き継ぐ）
- **制作年代**: 慶安3年（1650年）
- **形態・規模**: 1軸、縦 164.5 cm × 横 223.0 cm
- **内容・歴史的背景**:
  - 幕府による「正保国絵図（正保の国絵図）」編纂に際し、津久井領内27ヶ村がそれぞれ提出した村絵図を取りまとめて調製された領内惣絵図の控え（副本）。
  - 図の下方に津久井領内27ヶ村の村役人43名が連名で署名・押印。
  - 彩色表現: 平地（黄色）、山地（灰色）、幕府御林（黒色）、主要街道・間道（赤線）。
  - 津久井領全体の景観を描いた現存最古の地図資料であり、江戸初期の神社・寺院・関所・番所の立地が明記されている。
- **所蔵および公開状況**:
  - **所蔵先**: 個人所蔵（原則非公開・現地見学不可）。
  - **閲覧・複製手段**: 『津久井町史』各巻および相模原市立博物館の特別展図録・研究紀要に精細写真版が掲載されており、学術調査時はこれら出版物または博物館保管の複写原版を参照する。

## 5. NDL次世代OCR API 仕様・利用条件

国立国会図書館次世代システム開発研究室（NDL Lab）が提供する「次世代デジタルライブラリー」およびOCR APIに関する調査結果を取りまとめた。

### 5.1 サービス概要とエンドポイント

- **ポータルサイト**: `https://lab.ndl.go.jp/dl/`
- **API ドキュメント**: `https://lab.ndl.go.jp/service/tsugidigi/apiinfo/`
- **対象資料**: 国立国会図書館デジタルコレクションのうち、著作権保護期間満了資料（約35万点）
- **主要エンドポイント**:
  - `GET /api/book/{pid}`: 書誌情報および目次ツリー取得
  - `GET /api/page/{pid}/{page_number}`: 指定コマのOCR処理済み全文テキストおよび各行・各文字のバウンディングボックス座標（JSON）
  - `GET /api/search?keyword={query}`: OCR全文テキストに対する横断検索API

### 5.2 データ構造

各ページ（コマ）のテキストデータは以下の階層化JSONで返却される。

```json
{
  "pid": "763971",
  "page": 222,
  "width": 1824,
  "height": 2736,
  "lines": [
    {
      "line_index": 1,
      "text": "青野原村ハ東青山村ニ界シ",
      "bbox": [1520, 320, 1560, 1140],
      "chars": [
        {"char": "青", "bbox": [1520, 320, 1560, 375]},
        {"char": "野", "bbox": [1520, 375, 1560, 430]}
      ]
    }
  ]
}
```

### 5.3 利用条件と制約事項

1. **利用資格・認証**:
   - 公開資料（パブリックドメイン）に対するAPI利用は無料・登録不要。
   - APIキーの事前発行は不要で、HTTPクライアントから直接リクエスト可能。
2. **利用許諾**:
   - テキストデータはパブリックドメイン / CC0準拠。研究・二次利用・商用利用自由（クレジット「国立国会図書館次世代デジタルライブラリー」明記推奨）。
3. **アクセス制限と注意事項**:
   - 研究・実証実験サービスであるため、短時間の大量アクセス（毎秒1リクエスト超の過度なリクエスト）はサーバー負荷制限によりIP遮断される可能性がある。
   - バッチ取得時は `time.sleep(1.0)` 以上のインターバルを設定すること。
   - OCR結果は古典籍・旧字体・近代活字の機械認識であるため、くずし字や濁点・カスレによる誤認識（ノイズ）が含まれる。Phase 1での地名抽出時は形態素解析や正規表現による揺らぎ吸収が必須となる。
