## 1. 監査の背景と目的

Phase 0.4において、重点調査地域である相模原市緑区旧津久井4地区（青野原、青山、鳥屋、寸沢嵐）を対象として、国土地理院「地図・空中写真閲覧サービス」API（2026年3月リニューアル版仕様）より昭和期の空中写真42件を抽出しメタデータカタログを作成した。

しかしながら、データ品質監査において以下の3点の課題が確認された。

1. **欠損値センチネル（`1111-11-11`）の未正規化**:
   - 陸軍撮影写真の一部において、撮影日データが存在しない場合に国土地理院DB側でダミー値として設定された「1111年11月11日」がそのまま記録されていた。
2. **年代区分（`decade`）の不整合**:
   - 一部のレコードで年代区分が撮影年と一致せず、欠損レコードが誤って特定の年代に分類されるリスクがあった。
3. **点縮退範囲（ゼロ面積ポリゴン）の混在**:
   - 戦前・戦時中の古い写真において、四隅の被覆座標（`left_top`, `right_bottom` 等）が中心点と同一座標に縮退しており、GIS上でポリゴンとして扱うとエラーが発生する構造となっていた。

本Phase 0.4.1において、これら42件の全メタデータを正規化・タグ付けし、Phase 1における安全なGIS空間処理を保証する基盤を確立した。

## 4. 点縮退範囲（Degenerate Point Extent）の検出とGIS防護

### 4.1 点縮退現象の構造
空中写真の幾何補正情報において、古い写真（特に戦前・戦中の旧陸軍撮影写真）は、写真の四隅座標（左上、右上、右下、左下）の計測データが存在せず、撮影中心点座標（緯度・経度）のみが記録されている場合がある。

この場合、APIから返却される4頂点座標が全て同一値となり、バウンディングボックスの面積がゼロ（$\Delta\text{lat} = 0, \Delta\text{lon} = 0$）となる。これをGISライブラリ（GeoPandas, Shapely, GDAL, QGIS等）でポリゴンジオメトリ（`Polygon`）として変換しようとすると、トポロジ不正エラー（`TopologyException: Input geom 0 is invalid: Self-intersection or zero area`）が発生する。

### 4.2 品質タグの付与ルール
- 判定条件: `min_lat == max_lat` かつ `min_lon == max_lon`
- 点縮退時:
  - `footprint_status`: `"unknown"`
  - `is_point_only`: `true`
- 正常矩形時:
  - `footprint_status`: `"valid"`
  - `is_point_only`: `false`

### 4.3 検出結果
- **正常矩形範囲（有効バウンディングボックス）**: **34件**（81.0%）
- **点縮退範囲（中心点のみ有効）**: **8件**（19.0%）
  - 陸軍 C61系列: 6件（コース C1, 写真番号 5, 6, 7, 141, 142, 143）
  - 陸軍 B17系列: 2件（1942年撮影 コース C1, 写真番号 58, 59）

### 4.4 Phase 1 GIS解析における防護設計
```python
# Phase 1 での安全なジオメトリ変換例
def parse_aerial_footprint(record: dict):
    if record.get("is_point_only") or record.get("footprint_status") == "unknown":
        # ポリゴンではなく中心点Pointとして扱うか、名目バッファ（例: 半径1km）を生成
        center = record["center"]
        return shapely.geometry.Point(center["lon"], center["lat"])
    else:
        # 正常な4頂点ポリゴンを生成
        corners = record["corners"]
        return shapely.geometry.Polygon([
            (corners["left_top"]["lon"], corners["left_top"]["lat"]),
            (corners["right_top"]["lon"], corners["right_top"]["lat"]),
            (corners["right_bottom"]["lon"], corners["right_bottom"]["lat"]),
            (corners["left_bottom"]["lon"], corners["left_bottom"]["lat"]),
        ])
```

## 5. 測量法第27条第3項に基づく高解像度ダウンロードプロトコル

### 5.1 法令上の位置づけ
国土地理院が保管する空中写真原版の利用および交付は、**測量法第27条（成果等の複製）および第28条（謄本等の交付）**に規定されている。

- **閲覧およびウェブタイル利用**:
  - 「国土地理院コンテンツ利用規約」（CC BY 4.0互換）に基づき、出典明記により申請不要で利用可能。
  - 今回Phase 0.4で取得した1974年オルソ写真タイル4件（gazo1レイヤ）はこの規定に従い正規取得。
- **400dpi高解像度単写真ダウンロード**:
  - 国土地理院「地図・空中写真閲覧サービス」では、ユーザー登録（無料）を行った個人・団体に対し、測量法第27条第3項の包括承認に基づき、学術研究・調査目的での400dpi高解像度画像（JPEG/TIFF）の直接ダウンロードを無償で提供している。
  - **自動スクレイピングの禁止**: サービス利用規約により、APIやスクリプトによる一括自動ダウンロードは禁止されている。

### 5.2 手動ダウンロードの手順書
Phase 1において特定の遺構候補地（神社の旧境内、消滅集落の棚田跡等）の詳細写真が必要となった場合の手順は、`reports/phase0_4_manual_actions.md` 第2節に完全整備されている。

1. 国土地理院「地図・空中写真閲覧サービス」（`https://service.gsi.go.jp/map-photos/`）にログイン。
2. カタログ台帳（`tsukui_aerial_photos_catalog.json`）記載の整理番号（例: `USA-M198-1` 等）で検索。
3. 400dpi画像を選択し手動ダウンロード。
4. Google Drive上の `raw/aerial_photos/high_res_400dpi/` へ格納し、`provenance.jsonl` にハッシュ値を記録。
