# Phase 1-C2 地形解析の拡張設計（DEM連携）

状態: **設計のみ。今回の地形解析は未実施。**

## 1. 今回実施しなかった理由

- `processed/phase1b/` には検証済みの実DEM派生物（`terrain/dem`、`terrain/slope`）が存在しない（2026-10-11時点で `aerial/` と `manifests/` のみ）。
- 基盤地図情報DEMの原本（2009 DEM10B／2015 DEM5A・5B／2025 DEM5A・5B）は `raw/fgd/` に取得済みだが、Phase 1-B.5監査（`reports/phase1b5_data_quality.md`）で次の未解決事項が報告されている。
  - 2009・2015パッケージはShift_JIS、2025はUTF-8。Phase 1-BのGMLリーダはUTF-8前提。
  - 2025 DEM5Aは同一メッシュに版違い（例 20250214 と 20250620）が同居し、版選択規則が要る。
  - 2025の一部が `fguuid:jgd2024.bl` を宣言しており、水平CRSの扱いを確定する必要がある。
  - 2015 DEM5Aは `523951` が欠損し、DEM5Bのみ。
- Phase 1-C2の担当範囲はPhase 1-A派生物を使った独立分析であり、Phase 1-Bの基盤へのDEM取り込みは担当外。未検証のDEMを使った地形解析は行わない。

## 2. 前提条件（着手条件）

1. Codex等が実DEMを `processed/phase1b/terrain/dem/` にCOGとして公開し、manifestに原本SHA-256・内部ZIP名・`devDate`・DEM種別（5A/5B/10B）・水平CRS宣言・鉛直基準（T.P.）・NoData・セル寸法が記録されていること。
2. 独立基準点（三角点・水準点の公表標高など）で標高の誤差が確認されていること。
3. 傾斜は投影座標（m）のDEMから計算され、セル寸法の非等方性（5mメッシュは南北0.15秒・東西0.225秒）が処理されていること。

## 3. 結合方式

- 単位はPhase 1-C2と同じL03-b 100 mセル（JGD2011、メッシュコードで結合）。
- 各100 mセルについて、セル内の5 m DEM画素から統計量を集約する: 平均標高、標高の最小・最大・標準偏差、平均傾斜、傾斜の90パーセンタイル、傾斜≥30度の画素割合、斜面方位の循環平均。
- DEMの画素とセルの対応はセル多角形（EPSG:6677）を使ったゾーン統計で行う。重心サンプリングは使わない。
- 同じ指標を1 kmメッシュ・市区町村単位にも集約する。
- 地形分類（谷・尾根）はTPI（Topographic Position Index。半径100 m・500 mの2スケール）で定義し、閾値と半径を明記する。

## 4. 予定する分析

| 項目 | 方法 | 注意 |
|---|---|---|
| 標高と土地利用変化 | 標高帯ごとの遷移率（ブロック・ブートストラップ） | 標高と森林被覆が強く相関しているため、2014年の土地被覆類型で層別する |
| 傾斜と土地利用変化 | 傾斜帯ごとの農地→森林・荒地率、建物用地減少率 | 急傾斜地は2021年画像での判読差も起こりやすい |
| 山間集落の立地条件 | 建物用地セル（2014）の標高・傾斜・谷/尾根の分布を、地域・距離帯ごとに記述する | 集落の存否判定はしない |
| 道路距離と傾斜 | 2014年道路セルからの距離×傾斜帯の2元表 | OSM道路は2026年時点であり、2014年の状況として扱わない |
| 谷・尾根と土地利用 | TPI分類ごとの構成比と変化 | TPIの閾値への感度を報告する |

## 5. 標高比較時の統一事項

- 鉛直基準はすべて東京湾平均海面（T.P.）とし、DEM種別ごとに精度を記録する（5A：標準偏差0.3 m以内、5B：0.7 m以内、10B：5 m以内）。
- 年次の異なるDEMの差分は、計測方法の違い（レーザ・写真測量・等高線内挿）による差を含む。そのため「地形変化」とは解釈しない。差分を扱う場合は、同じ方式（5A同士）、同じ範囲、同じ再標本化方法に限り、平坦地の対照領域でバイアスを推定してから比較する。
- JGD2011とJGD2024の宣言を区別して保持し、変換の有無をmanifestに記録する。

## 6. 実装の差し込み口

- `kanagawa_ruins/landuse_change/` に `terrain_join.py` を追加し、`cells`（メッシュコード・EPSG:6677ポリゴン）とDEM COGのパスを受け取ってセル単位の統計量を返す関数を置く。
- `scripts/phase1c2_analyze.py` には `--dem-manifest` オプションを追加する。指定がない場合、地形の列は作らない（現状どおり）。
- テスト: 合成平面DEM（既知の傾斜）をセルに集約して理論値と照合する。実DEMについては、liveテストでmanifestのSHA-256と範囲を照合する。
