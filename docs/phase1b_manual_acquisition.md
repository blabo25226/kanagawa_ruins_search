# Phase 1-B 手動取得ガイド

調査日：2026-10-11。公式説明ページ・仕様書のみ確認しました。データの新規ダウンロード、認証、登録、購入、申請、規約同意は実行していません。以下の未取得項目は全て`manual_action_required`です。公式サービスの画面・条件は取得時に再確認してください。

## DEMを先に少範囲で取得

現有4タイルの範囲を含む2次メッシュ`533921`と`533931`を最初の候補にします。これは画像処理検証用の範囲であり、青野原・青山・鳥屋・寸沢嵐の大字境界を確定したものではありません。希望する研究範囲が外に広がる場合は利用者が追加メッシュを決めてください。

[基盤地図情報ダウンロードサービス](https://service.gsi.go.jp/kiban/app/)は利用者登録・ログインによる取得方式です。DEM10Bは全国整備、DEM5A（航空レーザ）・5B/5C（写真測量）は提供範囲図で確認します。津久井の各5m製品の収録状況はログイン/選択操作を行っていないため未確認です。まず範囲があれば5A、なければ5B/5C、広域確認用に10Bを検討してください。[公式FAQ](https://service.gsi.go.jp/kiban/app/faq/)に製品別の範囲・作成方法・メッシュ構成が記載されています。

提供はJPGIS GML形式のXMLを含むZIPです。10mは2次メッシュ、5mは3次メッシュ単位のセル配列を持ち、ダウンロードZIP名には2次メッシュとDEM製品種別が含まれます。現在の[ファイル仕様5.3（2026年7月）](https://service.gsi.go.jp/kiban/contents/screen/basismap/documents/FGD_DLFileSpecV5.3.pdf)はJGD2024を指定しています。水平の経緯度だけでなく、標高成果の改定時期・製品メタデータ・鉛直基準を確認してください。

[公式ヘルプ](https://service.gsi.go.jp/kiban/app/help/)の標高補正案内では2024標高成果への補正に`hyokorevBM_jgd2024_h.par`を案内しています。今回パラメータは取得しておらず、標高変換も実装していません。過去資料と標高値を混在させず、入力宣言を別々に保持します。取得料・登録方式はサービスの最新案内を確認し、保存・加工・公開の際は国土地理院コンテンツ利用規約と測量成果利用手続の適用を確認してください。一律に公開承認不要とは扱いません。

推奨配置は`$RUINS_DATA_ROOT/raw/fgd/`です。ZIPを解凍して原本を書換える必要はありません。提供日・水平測地系・標高成果・単位・確認資料URLを別メタデータとして保管し、処理時はreview済みreference JSONを指定します。現コードは現在のJGD2024 XMLをnative COGへ変換する基盤を持ちますが、実配布ファイルの適合検証とJGD2024 DEMの投影後地形処理は次の確認事項です。

現有カタログを機械集計した候補は次のとおりです。各年代で「撮影日が判明し近似撮影範囲を持つ最も早い記録」を1件ずつ選んでおり、画像の内容・位置精度・網羅性を評価した順位ではありません。中心位置・四隅の座標は未検証で、実画像は未取得です。詳細は[機械可読候補](../reports/phase1b_acquisition_candidates.json)を参照してください。

[地図・空中写真閲覧サービス](https://service.gsi.go.jp/map-photos/)で地域と整理番号・コース・写真番号から個別写真を探し、諸元の撮影日・主点位置・範囲を照合してください。IDは既存取得台帳に対応するJSONからの値で、今回オンラインの個別写真を再照合した値ではありません。

[公式ヘルプ](https://service.gsi.go.jp/map-photos/app/help)は400dpi写真のダウンロード可、高解像度オンライン閲覧・請求書作成にはログインが必要、一括ダウンロード不可と案内しています。400dpiダウンロード自体にログインが必須とは同資料から確認できないため、過去レポートの一律「400dpiはログイン必須」を引き継ぎません。主点位置は誤りを含み得る近似値であり、表示URLのmin/maxは撮影範囲ではない点にも注意が必要です。

高解像度データの有料提供は、[国土地理院の交付・提供案内](https://www.gsi.go.jp/MAP/HISTORY/koufu)で空中写真・正射画像等1点5,000円と案内されています。400dpi公開画像と有料提供は区別し、希望解像度・利用条件・実際の販売価格を個別に確認してください。原本の単写真は正射画像ではなく、GCPだけで地形起伏による歪みが解決したとは判断できません。

利用者が正式に取得した単写真は`raw/aerial_photos/single_photos/<specId>/`など、4枚のXYZサンプルと分けて配置します。写真IDとファイルの対応表・取得時刻・提供解像度・出典・条件を登録してください。現状は単写真0件のため42件全て`not_acquired`です。将来、未対応の画像が存在した場合、現コードは対応を推測せず`unknown`に戻します。個別写真の取得状態を確定するには、対応表をレビューして`normalize_catalog(..., acquired_spec_ids=...)`へ渡してください。

## 旧版地形図の図幅を照合

要求された地名をそのまま正式図幅名として注文しないでください。今回の公式資料調査で確定した情報と未確認事項を分けます。

|要求された地名|確認結果|取得前の作業|
|---|---|---|
|青野原|現行図葉名と2次メッシュ533921を公式資料で確認|旧版の図歴・測量/修正年・リスト番号を検索して版を指定|
|相模湖|公式刊行資料では「与瀬」に相模湖を収録|旧版で「相模湖」という図名の版があるかを図歴で確認。与瀬533931も検索|
|城山|津久井の希望範囲に対応する正式旧版図幅名・版は未確認|地名検索と地図範囲検索を併用し、対象地域を確認|
|中津川|津久井・神奈川の希望範囲に対応する正式旧版図幅名・版は未確認|同名の他地域と区別して河川の希望区間を図上で指定|

図名/メッシュの根拠は[国土地理院の2次メッシュ対照表](https://www.gsi.go.jp/common/000218188.pdf)、相模湖の収録は[地形図刊行に関する公式資料](https://www.gsi.go.jp/common/000092288.pdf)です。周辺では青野原・与瀬・八王子等の図葉を範囲から照合してください。過去レポートにある図幅・年次の組合せは今回の調査で確認できておらず、取得済み・確認済みと扱いません。

最初は「戦前」「1950～1960年代」「1970年代」の比較用各1版を候補にします。これは希望年代であり、その年代の各図幅の実在版を確認したものではありません。[地図・空中写真閲覧サービス](https://service.gsi.go.jp/map-photos/)の図歴検索で測量年、修正年、発行年を別々に記録してください。

[公式交付案内](https://www.gsi.go.jp/MAP/HISTORY/koufu)によれば、旧版地図データはTIFF、600dpiまたは400dpi、図郭外の整飾を含み、座標値を持たない画像です。データ提供手数料は1点2,000円。窓口・郵送・e-Gov電子申請があり、送料は別です。柾判の2.5万/5万分1旧版データには別途刊行販売の経路もあります。高精細閲覧・サービス上の請求書作成はログインが必要です。申請・決済は利用者が行ってください。

推奨配置は`raw/historical_maps/<official_sheet_id>/<edition>/`です。原本TIFFをそのまま保存し、図名・図歴ID・版年・測地系・入手証憑・ライセンスを付記します。提供画像を位置合わせ済みGeoTIFFと誤認しないでください。印刷図のスキャンを使う場合は、スキャン解像度・トリミング・回転の有無も記録します。

## 1976年土地利用の測地変換は保留

[公式TKY2JGD案内](https://www.gsi.go.jp/sokuchikijun/tky2jgd_download.html)にはTokyo Datum→世界測地系用のソースコード、全国`TKY2JGD.par` Ver.2.1.1/2.1.2、地域別パラメータが掲載されています。Windowsインストーラの提供は2017年終了し、測量計算サイトが案内されています。今回はソフト・パラメータ・新しい検証点を取得していません。

JGD2000→2011の地域・時期に応じた地殻変動補正は[国土地理院の補正パラメータ案内](https://www.gsi.go.jp/sokuchikijun/sokuchikijun41012.html)で別に確認が必要です。Tokyo Datumの標準楕円体変換だけで高精度変換が成立したとは扱いません。

現在のPROJ 9.9.0で`TransformerGroup(4301,6677,allow_ballpark=False)`を調べた結果、利用可能操作0件、`tky2jgd.gsb`等が欠けていました。[機械可読結果](../reports/phase1b_datum_research.json)に候補操作・必要グリッド・取得URLの欠損を記録しています。公式`.par`はPROJの`.gsb`と同一形式ではなく、改名だけで利用できません。必要パラメータの利用条件、正規な形式変換、公式検証点での一致を別途確認してから、新しい処理版・レイヤーIDで派生物を作成してください。今回1976年GeoParquetは変換・上書きしていません。

## 入手後の原本登録

1. 利用者が取得・保存・加工条件を確認し、必要な登録・申請・同意を行う。
2. 本物のDriveマウントを確認し、新しいraw配下へ原本を配置する。既存原本と台帳を置換しない。
3. 出典URL、source_id、相対パス、実容量、SHA-256、取得時刻、対象年次、ライセンスをPhase0の取得・登録手順で記録する。取得日と撮影/測量年を区別する。
4. 台帳との照合・フル監査後、Phase1B inventoryとdry-runで不足情報を確認する。
5. GCP/DEM referenceを別途レビューして処理し、画像の位置精度・標高値・NoDataを検証する。

Phase1Bには未取得資料の自動収集や台帳追記機能はありません。今昔マップ画像の保存、連続タイル取得、候補地点の公開も行いません。
