# データ準備・取得ギャップ一覧（2026-10-22 / GitHub＋公式ページ調査）

**観測の種類を厳格に区別**: この表の「GitHub証跡」は過去のレポートに基づく判定であり、2026-10-22にDriveで再SHAを計算した結果ではない。「公式公開」は配布元サイトで項目を確認したという意味で、**取得済み/実ファイル検証済み**ではない。用途は次サイクルの作業計画・QAである。データ自身の台帳（`provenance.jsonl`）の代わりにはならない。

## 1. 管理状態の凡例

| 状態 | 具体的な意味 |
|---|---|
| `HISTORICAL_VERIFIED` | 過去の特定時点に実ファイルSHA等を再照合して成功した証跡がある。現在の遠隔実体の照合ではない |
| `ANALYZED_SCOPED` | 指定した期間・収録領域に限り分析を実行した |
| `PUBLISHED_REPORTED` | 過去の実行報告が保存を記録している。現時点でリモートSHAを再検証したわけではない |
| `REMOTE_UNVERIFIED` | マウント側の検査だけ／remote upload実体の独立検証が未完了 |
| `PUBLIC_NOT_ACQUIRED` | 公式サイトで公開を確認したが、当データバンクで取得・SHA検査・登録した証拠がない |
| `BLOCKED` | Drive 403、CRS等の実行不可条件が残る |
| `UNKNOWN` | GitHub上の資料だけでは決められない。未観測を「0」としてはいけない |

### 取得前に必要な確認／取得後に必要なQA

1. 公式利用規約、機械的取得の許否・利用条件、固定できる正式download URLを確認し、取得プランに記載。**新規ダウンロードは別承認**。
2. 同一対象地域での2014／2021のコード集合一致、同じ100mセルの地理的位置、重複、未知土地利用コード、欠損・海域、DEM/FGDとの測地整合を検査。正式な発行年度と衛星撮影時点を区別する。
3. 既存2014/2021の5338・5339と一緒に再集計する場合、旧結果v0.2.0を上書きせず**新分析版**としてmanifest・SHA・coverageを保存する。
4. 2021高解像度化に伴う判読差は、2014→2021間の相違を解析する際の独立のバイアスとして記録。
5. 5238・5239の原本が揃っても、各セルが完全に解析可能とは限らない。県土面積の分母、共通コード、有効陸域、年次欠損の観測可能性マスクが成立して初めて「解析率」を更新する。

## 4. C1・C2を結合する前の停止条件

- **共通面積**: 現時点でC1×C2の実分析領域は**5.95 km²**。C1を全域処理できない場合、C2を拡張しても実績値は県域統合に足りない。
- **格子**: C1のEPSG:6677 1,000m投影グリッド ≠ C2のJIS 3次メッシュ。未変換のIDをjoinしない。
- **時点**: C1 `2014→2025` ≠ C2 `2014→2021`。年版を同じイベント時刻とみなさない。
- **観測**: 建物ポリゴン数、道路縁線延長、土地利用100m優占分類は異なる観測。廃墟・廃神社判定ではない。
- **公開**: 個別座標・私有地候補・危険地域の位置を出さない。

**本ドキュメントは証跡の分類と公開データの配布状況のみを更新し、raw・台帳・Driveには触れていない。**
