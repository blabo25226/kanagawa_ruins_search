## 2. ChatGPTが実施した机上調査と新しい情報

国土数値情報の[2021年度L03-b公式配布ページ](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-L03-b-2021.html)により、現在のC2未収録1次メッシュ`5238`・`5239`の**2014年度版と2021年度版（世界測地系）の公開**を確認した。ファイル名、公開ページの概算容量は[データ準備マトリクス](20261022_data_readiness.md)に記録した。4 ZIPで約51.2 MB（圧縮表記値の合計）であり、**取得・保存・SHA照合・内部範囲の検証はまだしていない**。正式取得後も「県土100%解析済み」とは自動的にならない。

公式は2021年度に高解像度の衛星画像へ移行したため、2016年度以前との判読差が多いと注意喚起している。同一コード体系でも変化は真の土地利用変化と一致しない可能性がある。

### 3.1 分離ルール
- Codex: `codex/phase-next-c1-offline-preflight`、対象は `scripts/phase1c1*`・C1関連 `src/`・`tests/test_phase1c1*`・専用レポート。C2関連は触らない。
- Claude Code: `claude/phase-next-c2-coverage-qa`、対象はC2 `src/kanagawa_ruins/landuse_change/`・`scripts/phase1c2*`・`tests/test_phase1c2*`・専用レポート。C1関連は触らない。
- 両者とも**最新mainからそれぞれ独立したworktree/branch**、原本/派生物/既存台帳/認証/rclone設定を変更しない。ユーザーによるPRレビューまでmainへマージしない。
- 別のAIをCLI経由で自動召喚しない。Issueの作成は**エージェントの実行開始を保証しない**。実行者は各自の既存認証済みCLIなどでタスクを開始する。

## 4. Phase 1-Dの最低限の統計仕様（提案段階）

1. **分母**: 地物数だけではなく、県内かつ両年に比較可能な面積・観測範囲を記録。観測不可能な地域を変化0として扱わない。
2. **格子**: 主案はJIS標準地域メッシュへの再集計（C2との互換性を優先）。C1の既存投影1 kmグリッドIDをJISメッシュコードへ直接結合してはいけない。C1の地物レベルまたは形状付きセルの保持を確認してから決める。EPSG:6677の1 km正方格子は感度分析候補とする。
3. **期間**: C1 2014→2025とC2 2014→2021は異なる。両者の一致は同期した出来事の証明にはならない。「異期間比較」の列を持ち、可能なら後に版を揃える（そのためのデータ取得は未許可）。
4. **状態**: B（建物記録差）/L（土地利用分類差）/R（道路縁不一致）はそれぞれ`change`/`stable`/`unknown`。欠測原因と観測可能性を別列に保存。統合スコアで地点を順位化しない。
5. **評価**: 合成注入、0変化負の対照、空間ブロック（5 km主案、3/10 km感度）、判読差、閾値感度、海域/自治体境界/縮尺差を明示。
6. **公開**: 個別地物・私有地の位置・敏感な文化財地点は公開しない。公開前レビュー、少数セル抑制、1 km以上の集計を基本とする。

## 5. 追加の判断が必要な事項

- **G1 / Dataset acquisition**: `5238`/`5239`の2014/2021 ZIPを正式に取得するか。取得する場合は合計4件の具体的plan（ファイル名/URL/利用規約/容量/保存先/期待メタデータ/QA）を事前提出し、承認を得る。
- **G2 / Drive resumption**: 共有Drive API HTTP 403解消をどう確認するか。独自OAuthクライアント作成やキャッシュ設定変更は勝手に実施しない。既存9件のremote SHAが未確認のため、FUSE readbackだけで再開しない。
- **G3 / Real Phase 1-D execution**: 両系列のcoverageが足りるか、期間・格子・マスク・評価仕様がレビュー済みかを審査し、別途実行可否を決める。
