# Command: submit-review

`reports/review_request.md`に以下を記載する：

- 実在するコミットハッシュとリモートURL
- `reports/setup_report.md`の成功/失敗と依存関係のバージョン
- `reports/data_inventory.md`の取得物と未取得物
- `git status --short` と `git diff --check` の結果
- 取得物が追跡対象になっていない証拠
- レビュアーに判断してほしい事項（CRS設計・ソース優先度・次フェーズのスコープ）

これを提示しPhase 1に進まず停止する。
