# Skill: Source Audit

## 対象

`source.md`に登録された公開データ源。一次情報、ライセンス、手動・自動取得可否を検証する。

## 手順

1. URL到達、更新年月日、対象地域（相模原市緑区を含むか）を確認。
2. データ形式（GeoJSON, SHP, GML, CSV, TIFF, ZIP）、座標系と原典年を記録。
3. 表示・ダウンロード・再配布の権利を別々に確認。
4. URL発見は公式ページ/正規APIからのみ。ファイルパスを推測しない。
5. 取得許可のないものは`manual`扱いにして自動処理を止める。
6. `reports/data_inventory.md`へソース・条件・未取得理由を転記。

## 危険なパターン

- 連番の地図タイル総当り
- 今昔マップ画像のPC保存
- GSI高画質閲覧画像のキャプチャ
- 認証が必要なAPIへの回避的アクセス
- 配布条件不明のサイトの一括ダウンロード
